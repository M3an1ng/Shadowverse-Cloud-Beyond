## ADDED Requirements
### Requirement: Chained abilities trigger after generated event commits
The system SHALL execute chained abilities only after all events generated by the parent effect have been processed and their Commit has completed.

#### Scenario: Draw targets resolved before chained ability
- **WHEN** an effect generates a DrawEvent that resolves targets during Commit
- **THEN** chained abilities observe the committed DrawEvent targets

### Requirement: Chained ability gating uses final effect outcome
The system SHALL determine the effect outcome after processing generated events and use that outcome to decide whether chained abilities execute according to FailureHandling.

#### Scenario: Commit failure counts as effect failure
- **WHEN** an effect handler succeeds but a generated event commit fails
- **THEN** the effect outcome is failure and chained abilities follow FailureHandling

#### Scenario: CompleteWithFailure still runs chained abilities
- **WHEN** an effect outcome is failure and FailureHandling is CompleteWithFailure
- **THEN** chained abilities still execute using the effect completion trigger
