# Change: 统一事件公告与调试指令解析接口

## Why
- 目前通过 switch 手动构建公告/日志映射，易漏加导致 UI 显示异常（如 HandPlayabilityUpdateDto 进入日志）。
- 调试指令 `damage` 无参数时仍被当作成功发送，缺乏统一校验/错误回显。
- 需要明确哪些事件出现在前端日志，并为可提交事件提供统一的调试指令解析入口。

## What Changes
- 引入日志事件接口：事件自描述公告文本；仅实现该接口的事件出现在前端日志 UI。
- 为 `ICommittableEvent` 定义统一的调试指令解析接口/入口，集中参数校验并返回错误信息而非直接入管线。
- 去除前端/后端基于 switch 的手工映射，改用事件接口的实现结果渲染公告/指令。
- 修正调试指令错误处理：无参数/参数不合法时返回错误回显，不入事件管线。

## Impact
- Affected specs: event-log-interface
- Affected code: 事件模型（新接口）、调试指令处理/校验、日志广播/映射管线（前后端），现有事件类需补充接口实现。
