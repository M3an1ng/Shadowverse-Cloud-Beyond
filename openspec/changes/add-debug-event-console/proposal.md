# Change: 添加对战调试事件控制台

## Why
- 现有前端开发者控制台按钮未生效，缺少可用的调试入口。
- 需要在对战界面以 DEBUG 模式注入事件，便于快速验证事务性/可录制事件管线。
- 需要一套可操作、友好的事件触发指令，覆盖当前 `Server/Domain/Events` 下的事件，并在日志中以同样的可读格式展示，方便管理者即时修改和观测对局状态。

## What Changes
- 在对战界面启用仅限 DEBUG 的调试控制台，默认对普通玩家隐藏。
- 设计并实现用户友好的事件触发指令集（基于 `Server/Domain/Events` 现有事件：伤害/治疗/抽牌/资源/加卡/击杀/状态/进化/行动请求等），解析成可提交事件并即时生效。
- 将调试指令接入事务性/可录制事件管线（暂存→响应→提交），并在客户端回显成功/失败结果；后台事件日志也转换成同样的指令格式进行广播显示。

## Impact
- Affected specs: event-debug-console
- Affected code: 对战界面调试控制台 UI/交互、SignalR 调试指令通道、GameService 调试事件注入/校验、事件构建/映射工具。
