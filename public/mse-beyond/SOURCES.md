# MSE Beyond 测试页素材来源

- 来源目录：`D:/mse-svbyd-1.0.X`，用户提供的本地 MSE 包。
- `style` 与 PNG 文件原样复制自 `data/shadowverse-beyond.mse-style/`。
- `numbers/` 原样复制自 `shadowverse-symd`、`shadowverse-symp`、`shadowverse-syms` 符号字体包。
- `fonts/weibei-sc.woff2` 来自 `字体包/dfweibeiw7-gb.ttc` 中的 `DFPWeiBeiW7-GB`。
- `fonts/weibei-tc.woff2` 来自 `字体包/DFPWeiBei Modify.otf`。
- `fonts/noto-sans-sc.woff2` 与 `fonts/noto-sans-tc.woff2` 来自对应的 `NotoSansCJKsc-Medium.otf` 与 `NotoSansCJKtc-Medium.otf`，用于原模板指定的绘师和页脚。
- 字体通过 fontTools 转换为 WOFF2，保留原字体名称及版权元数据，未精简字形。
- 卡框、职业徽记、背景与相关图标属于原 Shadowverse / Shadowverse Worlds Beyond 素材；本地包未另附作者说明。
- 初始卡牌来自本项目 `data/card_data.json` 中 ID 为 `1401301` 的“治愈的旋律”，插画读取项目已有的 `assets/cards/1401301/preview.webp`。
- 该卡的展示说明按现有 `Heal(3)`（己方主战者）与 `Draw(1)` 能力填写，未接入或改写能力执行。
- 本页只作为本地私人学习和编辑体验测试，未接入正式游戏接口。
