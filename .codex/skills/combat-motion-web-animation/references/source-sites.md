# Source Sites

Use references intentionally. Do not collect dozens of links and hope taste emerges later.

## Gameplay VFX Reference

- `https://realtimevfx.com/`
  - Use for hit sparks, slash arcs, magical bursts, shockwaves, additive layering, timing, and breakdown thinking.
  - Search terms: `slash`, `impact`, `hit`, `card`, `magic`, `trail`, `flash`, `shockwave`.
- `https://www.artstation.com/`
  - Use for polished key art, VFX sheets, moodboards, and combat presentation direction.
  - Search terms: `card game vfx`, `attack effect`, `spell effect`, `combat ui`, `slash`.
- `https://www.behance.net/`
  - Use for motion boards, interface motion, HUD transitions, and presentation comps.
  - Search terms: `game ui motion`, `hud animation`, `card ui`, `combat interface`.

## Motion Direction Reference

- `https://motionographer.com/`
  - Use for pacing, emphasis, reveal logic, transitions, and professional motion language.
- `https://www.stashmedia.tv/`
  - Use for high-fidelity motion case studies and polished visual rhythm.

## Web Motion Reference

- `https://www.awwwards.com/`
  - Use for high-finish interaction design, transitions, and motion polish.
- `https://thefwa.com/`
  - Use for experimental and more aggressive interaction ideas.
- `https://tympanus.net/codrops/`
  - Use when you need articles that bridge inspiration to implementation.
- `https://gsapdemos.com/`
  - Use for practical timeline, SVG, path, and interaction animation examples.
- `https://rive.app/`
  - Use for interactive state-driven UI motion.
- `https://www.lottielab.com/`
  - Use for lightweight vector motion references and UI support animation.

## Collection Rules

- Capture 3-5 references per feature, not more.
- Force every reference into one job: motion path, hit treatment, layering, or timing.
- Discard references that look good but do not map to your target interaction.
- Pair at least one inspirational reference with at least one implementation-oriented reference.

## Fast Search Patterns

- For attack impact: `attack hit flash trail shockwave`
- For magical strike: `spell cast impact energy burst`
- For card UI motion: `card hover attack move dissolve`
- For board feedback: `screen shake hit stop white flash`
