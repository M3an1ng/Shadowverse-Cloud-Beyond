# 前端控制台

点击页面右上角的控制台图标，或按 Ctrl + 反引号打开/关闭。Esc 关闭，焦点回到原触发按钮。控制台不是模态窗口，可保持打开并操作页面。

## 日志来源

- 实际前端 console.log、info、warn、error、debug。
- 页面未捕获异常和未处理的 Promise 拒绝。
- 保留原生浏览器控制台的方法调用、参数及返回值；面板不会取代浏览器开发工具。
- 从入口初始化时开始采集，最近 500 条保留在本页内存；刷新页面会清空，不上传日志。
- 浏览器扩展、其他标签页、iframe 与浏览器内部网络诊断不在此面板采集范围内。

## 使用方式

| 控件 | 行为 |
|---|---|
| 级别 | 单独查看错误、警告、信息、日志或调试 |
| 搜索 | 不区分大小写，匹配消息、对象文本及错误堆栈 |
| 暂停显示 | 界面暂不更新，后台仍记录；继续显示后补齐记录 |
| 自动跟随 | 新消息滚动到底部；关闭后保留当前滚动位置 |
| 清空记录 | 清空面板缓存，不调用原生 console.clear |
| 复制筛选结果 | 复制当前条件匹配的日志；剪贴板拒绝访问时显示失败原因 |

对象按记录时的值显示，支持循环引用、BigInt 与 Error 堆栈。对象无法展开时明确显示原因，不让日志格式化破坏原始 console 调用。

## 与旧工具的关系

旧游戏命令控制台和命令解析测试已归档，不再提供命令执行、SignalR 轮询或游戏规则调试指令。原文在 archive/2026-10-23-dev-console。

开发工具页的“实时日志窗口”仍是独立的服务端日志来源，原有登录要求和条件追踪开关保持不变；前端面板不为服务端日志创建额外连接。
