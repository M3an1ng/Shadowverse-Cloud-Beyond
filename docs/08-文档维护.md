## 按变更更新文档

| 代码变化 | 对应文档 |
|---|---|
| 页面或用户功能 | 项目现状 |
| 依赖、启动端口、构建命令 | 开发与验证 |
| 模块职责或调用路径 | 架构与代码导航 |
| 回合、牌组、任务、房间生命周期 | 对战与玩法 |
| 能力字段、解析与编辑器读写 | 卡牌创作与 DSL |
| API、DTO、身份或数据库 | 接口与数据 |
| 配置、发布、日志或排障 | 运行部署与排障 |

版本从项目及锁文件核对，字段从 DTO 和模型核对，规则从当前实现核对。描述实现、构建通过和运行验证时分别说明证据，不将规划写成已完成功能。

## 仓库清洁规则

[.gitignore](../.gitignore) 排除所有以点开头的目录、备份、临时文件、构建产物、测试工程、测试页面及本地参考材料。根目录保留 `.gitignore`、`.gitattributes`、`.editorconfig` 等必要配置文件；Git 自身的 `.git` 元数据不属于版本文件。

从 Git 移除跟踪的本地材料可以继续留在本机，不再加入发布源码。业务源码、种子数据、实际参与编译的数据库迁移和发布脚本应保留。

## 完成检查

检查八份文档的本地链接都指向保留文件，并执行 [开发与验证](02-开发与验证.md) 中的编码和构建命令。涉及浏览器、对局、迁移或部署验证时，明确记录实际执行范围。
