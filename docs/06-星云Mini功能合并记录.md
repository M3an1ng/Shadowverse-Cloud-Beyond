# 星云Mini功能合并：第一批（2026-10-29）

原站目录：`I:/Shadowverse_Cloud_Beyond`。本批基于原站 C# / SignalR / 原生前端实现，未替换为 Mini 的 Node / React 架构。AI 保留原站，训练、评测和策略迁移暂缓。云服务器未更新。

## 已实现

|功能|配置与行为|
|---|---|
|激奏、结晶|能力基础信息仅勾选模式和填写费用，对应卡牌在效果配置绑定，保存时保留 `alternatePlay`；效果菜单加入声明入口。运行时复用原站出牌事务，只支付模式费用一次，支持0费，校验法术／护符类型与发动条件。激奏／结晶是声明出牌，保留预选事务绑定的实例；显式变身另行创建新实例。也支持通过同名效果声明 `CardDefinitionId`。|
|对应卡牌引用预览|按数据ID解析引用，局内直接随可见卡牌同步对应卡名、卡图、描述和属性，避免为一次预览额外加载完整能力库。静态卡牌详情复用原站目录缓存。|
|公开|保留原站公开事件和动画，不移动卡牌、不永久公开手牌；公开事件归属正确的卡牌拥有者。|
|亡召池筛选|新增 `PoolConditions` 可视化条件列表；`self` 指候选随从，启用条件取交集，先筛选再选最高合法费用，保留原站同费随机权重。无候选时无效果继续。|
|亡召属性修正|亡召上限接入原站 `ModifyAbilityKeyword`／光环修正通道。关键字选择亡者召还，对主战者施加；支持原站叠加、设置、倍乘等层，结果下限0。|
|变身新卡片实例|生成新实例编号，替换相同区域、位置的实体；原实例移除，旧目标引用不会自动指向新卡。重置临时状态、计数器与附加效果。事件传输附带旧编号→新编号映射，客户端同步区域、选择、动作缓存与预览；复制变身保留原站复制语义。|
|触发能力跳过选择|新增复选框 `SkipTargetAndModeSelection`，默认关闭。被触发能力包含玩家选目标、抉择模式，或静态序列／随机分支及连锁中的选择时，触发前整条跳过，优先于自动随机目标。动态分支无法静态确认时也跳过，避免执行一半后弹出选择。|
|局内卡片附加信息|显示实际属性／关键字修正、持续参数、来源与描述；同条件同持续方式的数值修正合计展示，并去重保留来源；不同条件、设值或倍乘分别展示，已失效效果不显示，保留原站隐藏摘要规则。|
|网页内居中弹窗|前端原生 `alert/confirm/prompt` 调用迁移至网页弹窗，确认流程异步等待结果，串行排队、取消与键盘焦点处理。模式／隐藏区域卡牌选择使用中央弹窗；混合区域候选统一列出，避免遮住可选目标。战场直接点选目标保留。|
|游戏操作设置|五项独立开关：目标选满自动确认、进化／超进化确认、模式选满自动确认、回合结束确认、融合确认。前四项默认开，融合默认关，浏览器本地持久化。|

## 使用入口

- 「系统设置 → 游戏操作设置」可更改上述五项开关。
- 工坊能力编辑「基础信息」勾选激奏／结晶关键字与费用，并选择对应卡牌；法术、护符类型由服务器最终校验。同一能力使用一种替代模式，需同时拥有两种模式时分别创建能力。
- 工坊效果「亡者召还」中编辑亡召池筛选；属性修正使用「调整能力关键字 → 亡者召还」，目标选择主战者。
- 工坊效果「触发能力」勾选「跳过选择目标和模式」。
