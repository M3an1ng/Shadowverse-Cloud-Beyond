# DSL 可视化编辑器使用指南（严格版）

本指南详解界面、按钮、选项分组、交互顺序和异常提示，确保每一步操作都可查。适用于卡牌条件、目标筛选等 DSL 表达式的可视化构建。

## 0. 前置条件
- 浏览器加载完成后，元数据需初始化成功（控制台出现 `MetadataDrivenComponent: Initialized with metadata`）。
- 若传入初始表达式，仅支持“属性链”与单层 `.query(<布尔表达式>)` 文本解析；其他情况请用界面重建。

## 1. 界面结构与状态
- **已完成表达式区**：显示虚拟根 `main` 的胶囊。绿色 ✓ 表示类型匹配完成；红色 × 表示类型不符。点击胶囊进入编辑该主表达式。
- **工作区**：当前编辑的子树，包含节点链与操作按钮。
  - 按钮：`[+]` 弹出选项菜单；`[×]` 清空并重置到主槽位；`[−]` 撤回/返回上级；`()` 将当前值节点封装为独立表达式写回主槽；`[✓]` 保存当前层（封装后写回父槽位并上升预览）。
  - 占位符：“?” 胶囊或空槽位提示必须填充，点击后进入对应槽位编辑。
- **选项菜单**：按“数据源/属性/函数/操作符/筛选”分组，依据当前位置类型过滤；鼠标悬停主分组出现子菜单，点击条目立即写入。
- **表达式预览**：工作区底部显示实时 DSL 字符串。
- **高亮规则**：当前编辑槽位的目标节点描边；选中节点加粗/变色；封装胶囊徽章显示完成/错误状态。

## 2. 从零创建一个简单比较表达式示例
1. 在工作区点击 `[+]`，在“数据源”选择一个上下文（如 `Target`）。
2. 再次点击 `[+]`，在“属性”选中目标属性（如 `HP`）；节点链显示 `Target.HP`。
3. 点击 `[+]`，在“操作符”选择数值比较（如 `>`）；工作区出现右操作数占位符 “?”。
4. 点击右侧 “?”，在“静态值”输入框填入数字（如 `5`）。类型自动推断为数值。
5. 点击 `[✓]`：当前层被封装写回父槽位，返回上级预览；主表达式胶囊应显示绿色 ✓。

## 3. 编辑现有表达式或子表达式
1. 点击上方主胶囊进入编辑；若要修改内部子表达式，点击对应嵌套胶囊或问号占位符。
2. 进入后，工作区载入该槽位的 AST 副本；`[+]` 添加或修改节点，完成后用 `[✓]` 保存写回父槽位。
3. 如需撤回一步，点击 `[−]`：优先移除右操作数，其次解封装或返回左侧；在子编辑器层再次 `[−]` 会退出该层。

## 4. 列表操作（集合查询/排序/截取）
1. 当类型为集合（`List<T>` 等）时，`[+]` 菜单会出现“筛选”分组的 `.query/.orderBy/.take`。
2. 选择 `.query` 后：
   - 源集合保持左侧；右侧出现筛选表达式占位符。
   - 点击占位符进入筛选槽位，`self` 自动绑定为集合元素类型，菜单仅显示该类型的属性/函数/操作符。
   - 完成筛选表达式后 `[✓]` 封装写回。
3. 选择 `.orderBy`：步骤与 `.query` 相同，槽位是排序键表达式，`self` 同样指向元素。
4. 选择 `.take`：槽位需要数值表达式（通常为静态数字或计算结果）。

## 5. 静态值输入与类型匹配
1. 选择“静态值”后，工作区显示输入框，默认标记为待输入。
2. 输入内容会自动推断类型：数字→数值，`true/false`→布尔，其他→字符串。父操作符的完整性同步更新。
3. 若父操作符类型不匹配，封装胶囊显示红色 ×；需调整输入或操作符类型使之兼容。

## 6. 封装与提升
- `[✓]`：对当前工作区 AST 执行封装并写回父槽位，再上升到父层预览。
- `()`：当工作区是单值节点时，直接封装为独立表达式并写回主槽位，方便将局部提升为可复用的主表达式。

## 7. 清空、撤回、退出
- `[×]`：重置工作区，重新初始化虚拟根 main（未保存的改动会丢失）。
- `[−]`：在当前 AST 内逐步撤回（右 → 左 → 解封装 → 清空）。若当前是子编辑器，持续点击可退出到上一级。

## 8. 选项分组与生效逻辑
- 数据源：上下文对象、静态值、函数返回值。
- 属性：基于当前节点返回类型的可用属性。
- 函数：参数首个类型与当前上下文匹配的函数。
- 操作符：按当前类型过滤（数值→算术/比较；布尔→逻辑；文本→等/包含类；对象→等/不等）。
- 筛选：仅集合类型出现的 `.query/.orderBy/.take`。

## 9. 解析器与类型限制
- 仅支持属性链与单层 `.query(<expr>)` 文本解析，复杂 DSL 文本需在界面重建。
- 元数据缺失或类型为 `Object` 时，菜单可用选项会减少；遇到类型徽章红色 × 时，检查左右操作数类型是否一致或逻辑操作是否为布尔。

## 10. 快速故障排查
- 看不到选项：确认已点击占位符或 `[+]`，且当前位置已有返回类型（必要时先选择数据源）。
- 保存失败提示“不完整”：使用工作区中的 “?”/红色 × 定位未填充或类型不匹配节点，补全后再 `[✓]`。
- 返回主表达式：点击主胶囊或使用 `[−]` 直至退出子层；如需彻底重做，点击 `[×]` 清空。
