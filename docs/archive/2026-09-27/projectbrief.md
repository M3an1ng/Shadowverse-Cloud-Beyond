# 项目简报 (Project Brief)

## 1. 项目目标 (Project Goals)

*   开发一款类《影之诗》的集换式卡牌游戏 (CCG)。
*   从网页版 Demo 开始，逐步迭代，最终可能迁移至 Unity。
*   实现与 AI 对战的核心玩法。
*   构建卡牌数据库和管理功能。
*   强调文档驱动开发和清晰的结构。

## 2. 核心特性 (Core Features - Initial Demo V0.1)

*   基础 1v1 对战逻辑 (回合管理, 抽卡, 出牌, 攻击)。
*   简化的卡牌属性 (费用, 攻击力, 生命值)。
*   基础资源系统 (如法力水晶)。
*   简单的 AI 对手。
*   基础卡牌数据显示。

## 3. 目标用户 (Target Audience)

*   CCG 爱好者。
*   对游戏开发感兴趣的初学者 (项目发起人)。

## 4. 技术栈 (Initial Tech Stack - Web Demo)

*   前端: HTML, CSS, JavaScript (可能使用框架如 Vue/React/Svelte 后续)
*   后端: (待定 - 可能是 Node.js/Express, Python/Flask, 或直接前端逻辑)
*   数据库: (初期使用 JSON 文件，后续可能迁移到 SQLite 或其他数据库)
*   游戏引擎 (未来): Unity + C#

## 5. 主要里程碑 (High-Level Milestones)

1.  **概念验证与网页版核心 Demo:** 实现基础对战逻辑和最简化卡牌/AI。
2.  **网页版功能扩展:** 丰富卡牌类型/效果，改进 AI，加入卡组编辑等。
3.  **技术选型与 Unity 迁移准备:** 调研方案，开始 Unity 核心逻辑实现。
4.  **Unity 版本深化与网站功能转型:** 完善 Unity 版本，网站转为官网/卡牌库。
