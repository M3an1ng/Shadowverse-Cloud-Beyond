# 09-配置管理系统 [COMPLETED]

## 目的与范围

本文档详细说明Shadowverse-beyond项目的配置管理系统实现，包括应用程序配置、环境变量管理、数据库连接配置、日志配置、前端构建配置以及开发/生产环境的配置差异化管理。涵盖完整的配置管理策略和最佳实践。

## 核心概念

### 配置管理组成
- **应用程序配置**: appsettings.json文件层次结构
- **环境配置**: 开发、测试、生产环境的差异化配置
- **连接字符串**: 数据库和外部服务连接配置
- **功能开关**: 特性标志和功能切换配置
- **安全配置**: 敏感信息的安全存储和管理

### 技术术语
- **Configuration Provider**: ASP.NET Core配置提供程序
- **Options Pattern**: 强类型配置选项模式
- **User Secrets**: 开发环境敏感信息存储
- **Environment Variables**: 环境变量配置
- **Configuration Binding**: 配置绑定到强类型对象

### 配置服务注册

#### Program.cs中的配置注册
```csharp
public class Program
{
    public static void Main(string[] args)
    {
        var builder = WebApplication.CreateBuilder(args);

        // 配置强类型选项
        ConfigureOptions(builder);

        // 配置服务
        ConfigureServices(builder);

        var app = builder.Build();

        // 配置中间件管道
        ConfigureMiddleware(app);

        app.Run();
    }

    private static void ConfigureOptions(WebApplicationBuilder builder)
    {
        // 绑定配置到强类型选项
        builder.Services.Configure<GameSettings>(
            builder.Configuration.GetSection(GameSettings.SectionName));

        builder.Services.Configure<EconomySettings>(
            builder.Configuration.GetSection(EconomySettings.SectionName));

        builder.Services.Configure<AISettings>(
            builder.Configuration.GetSection(AISettings.SectionName));

        builder.Services.Configure<DeveloperSettings>(
            builder.Configuration.GetSection(DeveloperSettings.SectionName));

        // 验证配置选项
        builder.Services.AddOptions<GameSettings>()
            .Bind(builder.Configuration.GetSection(GameSettings.SectionName))
            .ValidateDataAnnotations()
            .ValidateOnStart();

        builder.Services.AddOptions<EconomySettings>()
            .Bind(builder.Configuration.GetSection(EconomySettings.SectionName))
            .ValidateDataAnnotations()
            .ValidateOnStart();
    }

    private static void ConfigureServices(WebApplicationBuilder builder)
    {
        var developerSettings = builder.Configuration
            .GetSection(DeveloperSettings.SectionName)
            .Get<DeveloperSettings>() ?? new DeveloperSettings();

        // 根据配置条件注册服务
        if (developerSettings.EnableSwagger)
        {
            builder.Services.AddEndpointsApiExplorer();
            builder.Services.AddSwaggerGen();
        }

        if (developerSettings.EnableCors)
        {
            builder.Services.AddCors(options =>
            {
                options.AddDefaultPolicy(policy =>
                {
                    policy.WithOrigins(developerSettings.AllowedOrigins)
                          .AllowAnyMethod()
                          .AllowAnyHeader()
                          .AllowCredentials();
                });
            });
        }

        if (developerSettings.EnableHealthChecks)
        {
            builder.Services.AddHealthChecks()
                .AddDbContextCheck<ApplicationDbContext>();
        }
    }

    private static void ConfigureMiddleware(WebApplication app)
    {
        var developerSettings = app.Configuration
            .GetSection(DeveloperSettings.SectionName)
            .Get<DeveloperSettings>() ?? new DeveloperSettings();

        if (app.Environment.IsDevelopment() && developerSettings.EnableSwagger)
        {
            app.UseSwagger();
            app.UseSwaggerUI();
        }

        if (developerSettings.EnableCors)
        {
            app.UseCors();
        }

        if (developerSettings.EnableHealthChecks)
        {
            app.MapHealthChecks("/health");
        }
    }
}
```

### 配置使用示例

#### 在服务中使用配置
```csharp
public class GameService : IGameService
{
    private readonly GameSettings _gameSettings;
    private readonly EconomySettings _economySettings;
    private readonly ILogger<GameService> _logger;

    public GameService(
        IOptions<GameSettings> gameSettings,
        IOptions<EconomySettings> economySettings,
        ILogger<GameService> logger)
    {
        _gameSettings = gameSettings.Value;
        _economySettings = economySettings.Value;
        _logger = logger;
    }

    public async Task<GameStateDto> CreateGameAsync(string gameId, string playerId)
    {
        var gameState = new GameStateDto
        {
            GameId = gameId,
            MaxPlayers = _gameSettings.MaxPlayersPerGame,
            TurnTimeLimit = _gameSettings.TurnTimeLimit,
            Players = new List<PlayerStateDto>()
        };

        // 使用配置创建玩家状态
        var playerState = new PlayerStateDto
        {
            PlayerId = playerId,
            Health = _gameSettings.StartingHealth,
            MaxPP = _gameSettings.StartingPP,
            CurrentPP = _gameSettings.StartingPP,
            Hand = new List<CardInstanceDto>(),
            Field = new List<CardInstanceDto>(),
            Deck = new List<CardInstanceDto>()
        };

        gameState.Players.Add(playerState);

        _logger.LogInformation("游戏创建成功: {GameId}, 最大玩家数: {MaxPlayers}, 回合时间限制: {TurnTimeLimit}秒",
            gameId, _gameSettings.MaxPlayersPerGame, _gameSettings.TurnTimeLimit);

        return gameState;
    }
}
```

## 使用模式

### 配置热重载
```csharp
public class ConfigurationService : IConfigurationService
{
    private readonly IOptionsMonitor<GameSettings> _gameSettings;
    private readonly ILogger<ConfigurationService> _logger;

    public ConfigurationService(
        IOptionsMonitor<GameSettings> gameSettings,
        ILogger<ConfigurationService> logger)
    {
        _gameSettings = gameSettings;
        _logger = logger;

        // 监听配置变化
        _gameSettings.OnChange(OnGameSettingsChanged);
    }

    private void OnGameSettingsChanged(GameSettings newSettings)
    {
        _logger.LogInformation("游戏设置已更新: TurnTimeLimit={TurnTimeLimit}, MaxHandSize={MaxHandSize}",
            newSettings.TurnTimeLimit, newSettings.MaxHandSize);

        // 通知其他组件配置已更改
        ConfigurationChanged?.Invoke(newSettings);
    }

    public event Action<GameSettings>? ConfigurationChanged;
}
```
