## 先记住的差异

- 开发前端为 `127.0.0.1:5173`，API 和两个 SignalR Hub 代理到 `localhost:5100`。
- 账号登录不是旧文档所写的 JWT / Refresh Token 体系；详见接口文档的身份边界。
- 房间 `RoomId` 与单局 `ActiveGameId` 是不同概念。
- 回放基础设施存在，但默认配置关闭 Journal 写入，不等于默认持续录制。
- 任务完成、任务奖励领取是两个步骤；看到任务完成不等于金币已经到账。
