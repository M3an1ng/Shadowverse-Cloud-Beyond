# 项目现状

> 核对日期：2026-09-27。依据本地源码；“已有实现”不等于“已经上线”，也不代表本次已验证所有场景。

## 项目是什么

Shadowverse-Cloud-Beyond 是受影之诗启发的网页卡牌项目，包含实时对战、牌组构建、卡牌与能力编辑、调试工具，以及账号、任务和对局统计相关实现。浏览器使用原生 JavaScript 和 DOM；后端是 ASP.NET Core 8、SignalR 和 EF Core SQLite。

依赖版本来源：[package.json](../package.json)、[后端项目](../Server/ShadowverseBeyond.Server.csproj)、[SDK 配置](../global.json)。不要把旧文档中的架构目标、PostgreSQL 计划或功能完成百分比当作实际配置。

## 页面入口

由 [router.js](../src/router.js) 注册：`navigation`、`singleplayer`、`multiplayer`、`game`、`card-editor`、`deck-builder`、`dev-tools`、`dev-tools/match-lab`、`dsl-editor-v2`。单人和多人面板复用大厅容器，不是独立应用。

## 规划与当前实现分开

[目标功能地图](游戏界面目标功能地图.md) 中的卡牌图鉴新入口与收藏、剧情战役、战术挑战、个性化大厅属于目标设计。已有卡牌详情不等于图鉴系统，已有对战实验室不等于战术挑战，已有战场桌布不等于大厅定制。本文不为这些方向宣布完成。

同样，经济服务中存在卡包、金币和排名相关代码，不足以证明完整商城、抽卡界面或排位流程已上线。

## 已知文档与运行边界

- 旧启动、测试脚本与当前配置存在偏差，按 [开发与验证](02-开发与验证.md) 的直接命令操作。
- 账号相关请求仍显式传递用户 ID；当前身份边界应单独审查，不按旧 JWT 文档推断权限保证。
- 房间、对局和聊天相关运行状态包含内存存储，重启恢复能力应单独验证；持久化回放不等于恢复在线房间。
- OpenSpec 积累的变更尚未逐项完成实现核验；详见 [待核实清单](OpenSpec待核实清单.md)。
