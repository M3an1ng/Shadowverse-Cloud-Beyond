## 本地启动

终端一：

```powershell
dotnet run --project "Server/ShadowverseBeyond.Server.csproj" --launch-profile http
```

终端二：

```powershell
npm run dev
```

浏览器访问 `http://127.0.0.1:5173`。后端 HTTP 地址为 `http://localhost:5100`；Vite 的 `/api`、`/gamehub`、`/loghub` 代理均指向 5100。

来源：[launchSettings.json](../Server/Properties/launchSettings.json)、[vite.config.js](../vite.config.js)。

后端启动会应用数据库迁移并执行种子逻辑。连接字符串和数据库路径说明见 [接口与数据](06-接口与数据.md)。构建检查不需要启动后端或访问现有数据库。

## 最小人工冒烟

启动并确认迁移、种子日志无错误后：打开大厅 → 读取卡牌 → 建立牌组 → 开始一局 → 出牌、攻击、结束回合 → 返回大厅。联机另用两个浏览器上下文检查加入、准备、开局和重连；DSL 检查解析、修改、保存及重新打开。

构建成功只说明构建通过，不代表已完成上述浏览器和对局验证。
