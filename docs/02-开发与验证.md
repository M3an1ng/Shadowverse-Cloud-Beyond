## 环境与依赖

- [.NET SDK 配置](../global.json) 指定 `8.0.413`；实际可用版本遵循 SDK 的解析规则。本次环境解析为 `8.0.425`，不应写成任意 .NET 8 都适用。
- 前端依赖以 [package-lock.json](../package-lock.json) 为准。本次环境 Node `24.19.0`、npm `11.17.0`；这只是验证环境，不是新增的最低版本限制。
- Python 用于本仓库代码地图及文档校验，不是游戏运行时依赖。

```powershell
dotnet --version
node --version
npm --version
npm ci
dotnet restore "Server/ShadowverseBeyond.Server.csproj"
dotnet restore "Server.Tests/ShadowverseBeyond.Server.Tests.csproj"
```

`npm ci` 会重新安装锁文件中的依赖；已准备好的环境可跳过安装步骤。

## 启动两个终端

终端一：

```powershell
dotnet run --project "Server/ShadowverseBeyond.Server.csproj" --launch-profile http
```

终端二：

```powershell
npm run dev
```

浏览器访问 `http://127.0.0.1:5173`。后端 HTTP 地址为 `http://localhost:5100`。Vite 的 `/api`、`/gamehub`、`/loghub` 代理均指向 5100，Hub 代理启用 WebSocket。

来源：[launchSettings.json](../Server/Properties/launchSettings.json)、[vite.config.js](../vite.config.js)。开发模式 Swagger 入口见 [Program.cs](../Server/Program.cs)。

### 启动前的数据提醒

后端启动会调用 `Database.Migrate()` 和 `DataSeeder.SeedDatabaseAsync()`。因此启动不是纯只读检查：会应用已有迁移并执行种子逻辑。连接已有数据库前先核实连接字符串并备份；不要为了运行项目随手创建 `InitialCreate` 迁移。

默认 SQLite 连接的回退值为 `Data Source=Data/shadowverse.db`，相对路径受进程工作目录影响；先确认日志及实际文件，别把两处同名数据库混用。详情见 [接口与数据](06-接口与数据.md)。

## 测试命令

### 前端

```powershell
npm test -- --runInBand
npm test -- --runInBand --runTestsByPath "src/__tests__/routerSameRoute.test.js" "tests/emoteCatalog.test.js"
npm run build
```

Jest 使用 jsdom、Babel 转译和 [jest.setup.js](../tests/jest.setup.js)，配置位于 [package.json](../package.json)。测试分布在 `tests` 和 `src/__tests__`。安装了 Playwright 不等于所有浏览器测试已自动接入一个统一命令。

### 后端

```powershell
dotnet test "Server.Tests/ShadowverseBeyond.Server.Tests.csproj"
dotnet test "Server.Tests/ShadowverseBeyond.Server.Tests.csproj" --filter "FullyQualifiedName~DslMetadataServiceTests"
dotnet build "Server/ShadowverseBeyond.Server.csproj"
```

后端使用 xUnit；部分测试使用 EF InMemory 或应用测试宿主。运行集成测试前检查其数据库隔离设置，避免指向真实数据。

### 文档与编码

```powershell
python "scripts/check-docs.py"
npm run check:encoding
```

文档检查覆盖新的维护文档、兼容跳转和历史原文校验，不将旧档案中既有失效链接包装成当前文档错误。编码检查的范围和过滤规则见 [check-encoding.js](../scripts/check-encoding.js)。
