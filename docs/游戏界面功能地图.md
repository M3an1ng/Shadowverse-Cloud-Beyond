# 游戏界面功能地图（重构基线）

> 这是当前实现的事实基线，不是新的目标信息架构。重构中的目标场域、关键流程、页面边界和返回关系请参阅 [游戏界面目标功能地图.md](./游戏界面目标功能地图.md)。

> 目的：记录当前版本的页面、功能、状态与跳转关系，作为后续视觉重构的功能基线。本文按产品/UI 专业概念整理；不规定新视觉方案。

## 1. 信息架构总览

当前是单页应用（SPA），由 `src/router.js` 管理路由；页面通过 `.page` 的 `active` 状态切换，部分路由复用主菜单容器并以面板形式展开。

```text
navigation（主菜单/大厅）
├─ singleplayer（单人模式面板）
│  └─ game（实际对战战场）
├─ multiplayer（多人对战面板）
│  └─ game（实际对战战场）
├─ card-editor（卡牌工坊）
├─ deck-builder（牌组编辑）
├─ dev-tools（系统设置/开发者工具）
│  └─ dev-tools/match-lab（对战实验室）
└─ dsl-editor-v2（DSL 编辑器）
```

全局浮层：用户资料/认证、日常任务、关于与版本、PWA 安装提示、开发者控制台、卡牌详情/选择器、房间选择弹窗、退出对战确认。

## 2. 主界面：navigation（大厅 / Home）

### 2.1 视觉与布局角色
- 品牌 Hero 区：`SHADOWVERSE / WORLD BEYOND` 标题与副标题。
- 背景层：星空 Canvas、网格/HUD 线、5 个导航项对应的延迟加载场景图与能量连线动效。
- 主导航是五项垂直入口，属于**一级导航（Primary Navigation）**。

### 2.2 一级功能入口
| 入口 | 产品功能 | 关键动作 | 目标路由 |
|---|---|---|---|
| 单人模式 | 人机或本地双人练习 | 选择玩家/对手卡组，开始对战 | `singleplayer` |
| 卡牌工坊 | 创建、编辑、预览卡牌及能力 | 编辑基础属性、能力、素材、玩家设定 | `card-editor` |
| 牌组编辑 | 管理卡组、导入/导出代码 | 新建、编辑、复制、删除、校验、选择环境/规则 | `deck-builder` |
| 多人对战 | 在线房间联机 | 创建、加入、观战、进入战场 | `multiplayer` |
| 系统设置 | 实时日志、调试和运营数据 | 打开工具模块（通常需登录） | `dev-tools` |

### 2.3 大厅内嵌模块
- **单人模式面板**：练习对战；模式选择（人机/本地双人）；玩家卡组与 AI/对手卡组选择；地城解谜、剧情关卡为未开放占位入口。
- **多人模式面板**：当前卡组选择；创建房间；加入房间（GameId + JoinCode）；观战（输入 GameId 或查看房间列表）；进入对战；返回主菜单。
- **元进度面板**：输入 UserId、刷新摘要、领取每日奖励、任务列表。

## 3. 对战战场：game（Battle Screen）

这是核心沉浸式运行界面，路由进入时触发游戏初始化，离开时触发清理与退出确认。

### 3.1 HUD 信息架构
- 顶部：返回/投降入口、对手信息（头像、生命、资源、状态）。
- 中央：战场/随从与护符等牌面区域、回合与行动提示、特效层。
- 底部：玩家信息、手牌、资源与回合结束按钮。
- 侧/浮层：卡牌预览、详细说明、能力/关键词引用提示、表情与对战自定义（桌布）。

### 3.2 关键交互状态
`等待连接/初始化 → 换牌（Mulligan）→ 我方回合/对手回合 → 选牌/选目标/攻击/进化 → 结算与提示 → 胜负结果 → 返回大厅`。

### 3.3 边界行为
- 对战中点击离开、浏览器后退会触发投降确认。
- 桌布自定义仅在 `game` 路由可用；图片需裁切后保存。

## 4. 卡牌工坊：card-editor

**工具型编辑器（Editor Workspace）**，由 `cardEditor.js` 动态加载。
- 卡牌列表/搜索/筛选与选中态。
- 基础数据编辑：名称、费用、类型、职业、属性、描述等。
- 能力编辑：结构化 DSL/能力字段、引用与预览。
- 素材管理：预览图、详情图上传、裁切、路径显示。
- 玩家设定子页：领袖能力、种族/类型管理（启用、保留、别名、行为）。
- 右侧/下方预览：卡牌视觉稿、描述引用 tooltip、调试详情。
- 保存、删除、复制、刷新等 CRUD 操作；加载失败显示错误态。

## 5. 牌组编辑：deck-builder

**集合构建器（Deck Builder）**，由 `deckBuilder.js` 动态加载。
- 卡组列表与当前卡组选择。
- 新建流程：空白创建或导入卡组代码；导入后预览并进入编辑。
- 构筑区：卡牌目录、职业/类型/稀有度/卡包筛选、搜索、分页、排序。
- 已选卡牌区：数量增减、移除、费用曲线与统计。
- 规则校验：复制上限、环境/规则兼容性、卡组数量等；错误反馈阻止保存/开战。
- 卡组代码：导入、导出、复制。
- 生命周期：新建、编辑、保存、复制、删除（删除前确认）。

## 6. 系统设置与开发工具：dev-tools

登录门槛页面，属于**管理/诊断工作区**，不应与普通玩家主流程混在一起。
- 实时日志窗口：筛选级别、清空、导出 JSON。
- 对战实验室：配置 AI/本地双人对战参数，快速启动测试局（`dev-tools/match-lab`）。
- 开发者控制台：查看游戏状态、调试信息、条件追踪。
- API 测试：元数据 API 连通性验证。
- 数据库查看器入口：卡牌与能力数据查看（当前为开发中提示）。
- 管理员模块：用户管理、禁限卡牌管理、环境卡包配置。
- 胜率看板：卡牌、卡组、职业聚合胜率数据。

## 7. DSL 编辑器：dsl-editor-v2

独立的**领域专用语言（DSL）编辑工作区**，用于能力/效果结构化编辑；包含字段面板、AST/结构预览、校验与保存等能力，适合归类为内部创作工具。

## 8. 全局组件与跨页面状态

| 组件 | 触发位置 | 状态 |
|---|---|---|
| 用户卡片/认证 | 顶部用户入口 | 未登录、登录中、已登录、错误 |
| 日常任务 | 顶部任务图标 | 收起、展开、加载、可领取、已完成 |
| 关于 | 顶部信息图标 | 展开/收起；版本、技术栈、更新日志、PWA 安装 |
| 开发者控制台 | 全局按钮 | 展开/收起、日志流 |
| 卡牌详情 | 编辑器/战场/统计 | 加载中、完整详情、引用展开、空态 |
| 房间选择弹窗 | 多人观战 | 打开、房间列表、空态、关闭 |
| 通用反馈 | 各页面 | loading、success、error、confirm、empty |

## 9. 重构时必须保持的功能契约

1. 路由名称与入口语义保持一致，尤其是 `navigation / game / card-editor / deck-builder / multiplayer / dev-tools`。
2. 进入战场前必须完成卡组选择与校验；对战中离开必须二次确认。
3. 编辑器的保存、导入/导出、删除确认、素材裁切和错误反馈不可丢失。
4. 登录权限、管理员权限、任务领取等属于状态驱动 UI，不是静态装饰。
5. 所有弹窗需支持明确关闭、键盘/焦点可达和加载/空/错状态。

## 10. 推荐的重构页面分层

- **Shell 层**：全局顶栏、用户、任务、关于、通知、路由过渡。
- **Hub 层**：主菜单与模式入口（单人、多人、编辑、牌组）。
- **Play 层**：对战 HUD、战场、卡牌预览、结算。
- **Create 层**：卡牌工坊、牌组编辑、DSL 编辑器。
- **Operate 层**：系统设置、日志、实验室、胜率和管理员工具。
- **Overlay 层**：弹窗、确认、tooltip、toast、loading/error/empty 状态。
