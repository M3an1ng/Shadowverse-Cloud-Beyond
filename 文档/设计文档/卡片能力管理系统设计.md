## 📋 能力分类体系

### 🔥 **优先实现：触发式能力 (Triggered Abilities)**

触发式能力是影之诗的核心机制，在特定事件发生时自动触发。

#### **核心触发类型**
```
触发式能力
├── 入场触发 (Enter Battlefield)
│   ├── Fanfare (入场效果) - 🎯 优先级：高
│   └── Clash (冲突效果) - 🎯 优先级：中
├── 离场触发 (Leave Battlefield)  
│   ├── Last Words (离场效果) - 🎯 优先级：高
│   └── Destroy Effects (破坏效果) - 🎯 优先级：中
├── 战斗触发 (Combat Triggers)
│   ├── Attack Triggers (攻击时) - 🎯 优先级：中
│   ├── Damage Triggers (受伤时) - 🎯 优先级：中
│   └── Kill Triggers (击杀时) - 🎯 优先级：低
├── 回合触发 (Turn Triggers)
│   ├── Turn Start (回合开始) - 🎯 优先级：中
│   ├── Turn End (回合结束) - 🎯 优先级：中
│   └── Draw Triggers (抽卡时) - 🎯 优先级：低
└── 进化触发 (Evolution Triggers)
    └── Evolve Effects (进化效果) - 🎯 优先级：高
```

### ⚡ **优先实现：持久式能力 (Static Abilities)**

持久式能力提供持续的被动效果，是游戏的基础机制。

#### **核心持久类型**
```
持久式能力
├── 关键字能力 (Keyword Abilities) - 🎯 优先级：高
│   ├── 移动相关
│   │   ├── 突进 (Rush) - 🎯 优先级：高
│   │   ├── 疾走 (Storm) - 🎯 优先级：高
│   │   └── 潜行 (Stealth) - 🎯 优先级：中
│   ├── 防御相关
│   │   ├── 守护 (Ward) - 🎯 优先级：高
│   │   └── 不能被选择 (Untargetable) - 🎯 优先级：中
│   └── 战斗相关
│       ├── 吸血 (Drain) - 🎯 优先级：中
│       └── 必杀 (Bane) - 🎯 优先级：中
├── 属性修改 (Stat Modifications) - 🎯 优先级：中
│   ├── 攻击力加成/减少
```

## ⚙️ **核心设计决策**

### 🔄 **触发优先级和队列机制**

#### **队列结算原则**
- **基础规则**：触发式能力按照触发顺序进入队列，先进先出 (FIFO)
- **插队机制**：某些能力可以插队到队列前端（如反击、强制响应）
- **嵌套处理**：一个能力触发另一个能力时，新能力插入到当前位置之后

#### **队列实现结构**
```csharp
public class AbilityQueue
{
    private Queue<AbilityExecution> _normalQueue = new();
    private Queue<AbilityExecution> _priorityQueue = new();

    public void Enqueue(AbilityExecution execution, bool isPriority = false)
    {
        if (isPriority)
            _priorityQueue.Enqueue(execution);
        else
            _normalQueue.Enqueue(execution);
    }

    public AbilityExecution? Dequeue()
    {
        // 优先队列优先处理
        if (_priorityQueue.Count > 0)
            return _priorityQueue.Dequeue();

        return _normalQueue.Count > 0 ? _normalQueue.Dequeue() : null;
    }
}
```

#### **能力队列管理器**
```csharp
public class AbilityQueue
{
    private readonly Queue<CardAbility> _beforeQueue = new();
    private readonly Queue<CardAbility> _onQueue = new();
    private readonly Queue<CardAbility> _afterQueue = new();

    public void Enqueue(CardAbility ability, AbilityPhase phase)
    {
        switch (phase)
        {
            case AbilityPhase.Before:
                _beforeQueue.Enqueue(ability);
                break;
            case AbilityPhase.On:
                _onQueue.Enqueue(ability);
                break;
            case AbilityPhase.After:
                _afterQueue.Enqueue(ability);
                break;
        }
    }

    public async Task<List<GameEventDto>> ProcessAllAsync(GameContext context)
    {
        var events = new List<GameEventDto>();

        // 按优先级顺序处理
        events.AddRange(await ProcessQueueAsync(_beforeQueue, context));
        events.AddRange(await ProcessQueueAsync(_onQueue, context));
        events.AddRange(await ProcessQueueAsync(_afterQueue, context));

        return events;
    }
}
```

```csharp
public class EventProcessor
{
    private readonly Queue<IGameEvent> _eventQueue = new();
    private readonly List<ICardAbility> _activeAbilities = new();
    private readonly ILogger<EventProcessor> _logger;

    public async Task<List<GameEventDto>> ProcessEventAsync(IGameEvent initialEvent, GameContext context)
    {
        var processedEvents = new List<GameEventDto>();
        _eventQueue.Enqueue(initialEvent);

        while (_eventQueue.Count > 0)
        {
            var currentEvent = _eventQueue.Dequeue();

            // 1. 执行Event本身
            var newEvents = await currentEvent.ExecuteAsync(context);

            // 2. 记录Event
            processedEvents.Add(ConvertToDto(currentEvent));

            // 3. 检查是否触发能力
            var triggeredAbilities = await GetTriggeredAbilitiesAsync(currentEvent, context);

            // 4. 执行触发的能力，产生新Event
            foreach (var ability in triggeredAbilities)
            {
                var abilityEvents = await ability.OnTriggeredAsync(currentEvent, context);
                foreach (var abilityEvent in abilityEvents)
                {
                    _eventQueue.Enqueue(abilityEvent);
                }
            }

            // 5. 将Event本身产生的新Event加入队列
            foreach (var newEvent in newEvents)
            {
                _eventQueue.Enqueue(newEvent);
            }
        }

        return processedEvents;
    }

    private async Task<List<ICardAbility>> GetTriggeredAbilitiesAsync(IGameEvent gameEvent, GameContext context)
    {
        var triggeredAbilities = new List<ICardAbility>();

        foreach (var ability in _activeAbilities)
        {
            if (ability.TriggerEvents.Contains(gameEvent.EventType))
            {
                if (await ability.ShouldTriggerAsync(gameEvent, context))
                {
                    triggeredAbilities.Add(ability);
                }
            }
        }

        return triggeredAbilities;
    }
}
```

### 🔄 **统一的Event-Dto转换机制**

```csharp
// Event处理器中的统一转换
public class EventProcessor
{
    public async Task<List<GameEventDto>> ProcessEventAsync(IGameEvent initialEvent, GameContext context)
    {
        var processedEvents = new List<GameEventDto>();
        _eventQueue.Enqueue(initialEvent);

        while (_eventQueue.Count > 0)
        {
            var currentEvent = _eventQueue.Dequeue();

            // 1. 执行Event本身
            var newEvents = await currentEvent.ExecuteAsync(context);

            // 2. 转换为Dto并记录
            var eventDto = ConvertEventToDto(currentEvent);
            processedEvents.Add(eventDto);

            // 3. 检查并触发能力
            var triggeredAbilities = await GetTriggeredAbilitiesAsync(currentEvent, context);
            foreach (var ability in triggeredAbilities)
            {
                var abilityEvents = await ability.OnTriggeredAsync(currentEvent, context);
                foreach (var abilityEvent in abilityEvents)
                {
                    _eventQueue.Enqueue(abilityEvent);
                }
            }

            // 4. 将Event产生的新Event加入队列
            foreach (var newEvent in newEvents)
            {
                _eventQueue.Enqueue(newEvent);
            }
        }

        return processedEvents;
    }

    private GameEventDto ConvertEventToDto(IGameEvent gameEvent)
    {
        // 每个Event都有ToDto()方法，与现有Dto完美对应
        return gameEvent switch
        {
            // 基础游戏操作Event (对应现有Dto)
            PlayCardEvent e => e.ToDto(),                    // → CardPlayedEventDto
            SummonEvent e => e.ToDto(),                      // → CardSummonedEventDto
            DrawEvent e => e.ToDto(),                        // → CardDrawnEventDto
            AttackDeclaredEvent e => e.ToDto(),              // → AttackDeclaredEventDto
            DamageEvent e => e.ToDto(),                      // → DamageDealtEventDto
            UnitDestroyedEvent e => e.ToDto(),               // → UnitDestroyedEventDto
            EvolveEvent e => e.ToDto(),                      // → UnitEvolvedEventDto
            HealthChangedEvent e => e.ToDto(),               // → HealthChangedEventDto
            StatChangedEvent e => e.ToDto(),                 // → StatChangeEventDto
            TurnStartEvent e => e.ToDto(),                   // → TurnStartedEventDto
            TurnEndEvent e => e.ToDto(),                     // → TurnEndedEventDto
            PpUpdateEvent e => e.ToDto(),                    // → PpUpdateEventDto

            // 能力系统专用Event (新增Dto)
            AbilityTriggeredEvent e => e.ToDto(),            // → AbilityTriggeredEventDto

            // 扩展Event (对应现有Dto)
            EpUpdateEvent e => e.ToDto(),                    // → EpUpdateEventDto
            DeckUpdateEvent e => e.ToDto(),                  // → DeckUpdateEventDto
            GraveyardUpdateEvent e => e.ToDto(),             // → GraveyardUpdateEventDto
            GameOverEvent e => e.ToDto(),                    // → GameOverEventDto
            ErrorEvent e => e.ToDto(),                       // → ErrorOccurredEventDto

            _ => throw new NotSupportedException($"Event type {gameEvent.GetType().Name} not supported")
        };

}
```

```csharp
    private readonly Dictionary<TriggerTiming, Queue<PendingTrigger>> _pendingTriggers = new();

    public void AddPendingTrigger(TriggerTiming timing, PendingTrigger trigger)
    {
        if (!_pendingTriggers.ContainsKey(timing))
            _pendingTriggers[timing] = new Queue<PendingTrigger>();

        _pendingTriggers[timing].Enqueue(trigger);
    }

    public async Task<List<IGameEvent>> ProcessTriggersForTiming(TriggerTiming timing, GameContext context)
    {
        var events = new List<IGameEvent>();

        if (_pendingTriggers.TryGetValue(timing, out var triggers))
        {
            while (triggers.Count > 0)
            {
                var trigger = triggers.Dequeue();
                var triggerEvents = await trigger.ExecuteAsync(context);
                events.AddRange(triggerEvents);
            }
        }

        return events;
    }
}
```

```csharp
// 简化的优先级定义
public class TriggerPriority
{
    public TriggerTiming Timing { get; set; } = TriggerTiming.After;
    public int Order { get; set; } = 0;  // 同一时机内的执行顺序，0为默认（先入先出）
}

// 简化的优先级管理器
public class TriggerPriorityManager
{
    public List<PendingTrigger> SortByPriority(List<PendingTrigger> triggers)
    {
        return triggers
            // 1. 按时序排序：During → After → EndOfPhase → EndOfTurn → Immediate
            .OrderBy(t => GetTimingOrder(t.Priority.Timing))
            // 2. 同一时序内按Order排序
            .ThenBy(t => t.Priority.Order)
            // 3. Order相同时按添加顺序（先入先出）
            .ThenBy(t => t.AddedTimestamp)
            .ToList();
    }

    private int GetTimingOrder(TriggerTiming timing)
    {
        return timing switch
        {
            TriggerTiming.During => 1,
            TriggerTiming.After => 2,
            TriggerTiming.EndOfPhase => 3,
            TriggerTiming.EndOfTurn => 4,
            TriggerTiming.Immediate => 0,  // 立即执行，最高优先级
            _ => 999
        };
    }

    public async Task<List<IGameEvent>> ProcessTriggersInOrder(List<PendingTrigger> triggers, GameContext context)
    {
        var events = new List<IGameEvent>();
        var sortedTriggers = SortByPriority(triggers);

        foreach (var trigger in sortedTriggers)
        {
            // 检查触发器是否仍然有效
            if (await IsStillValidAsync(trigger, context))
            {
                var triggerEvents = await trigger.ExecuteAsync(context);
                events.AddRange(triggerEvents);

                // 更新游戏状态，可能影响后续触发器
                await context.UpdateStateAsync(triggerEvents);
            }
        }

        return events;
    }

    private async Task<bool> IsStillValidAsync(PendingTrigger trigger, GameContext context)
    {
        // 检查触发器的源卡牌是否仍在有效状态
        return trigger.SourceCard.Zone != CardZone.Destroyed;
    }
}
```

```csharp
// 重新设计的条件系统
public abstract class Condition
{
    public string Id { get; set; } = Guid.NewGuid().ToString(); // 条件唯一标识
    public abstract Task<bool> EvaluateAsync(ConditionContext context);
}

// 简单条件：检查单个属性
public class PropertyCondition : Condition
{
    public ConditionTarget Target { get; set; } = new();        // 检查目标（增强版）
    public string Property { get; set; } = string.Empty;       // 属性名称
    public ComparisonOperator Operator { get; set; }           // 比较操作符
    public Value ExpectedValue { get; set; } = new();          // 期望值

    public override async Task<bool> EvaluateAsync(ConditionContext context)
    {
        var targets = await Target.SelectAsync(context);
        if (!targets.Any()) return false;

        foreach (var target in targets)
        {
            var actualValue = await GetPropertyValueAsync(target, Property, context);
            var expectedValue = await ExpectedValue.ResolveAsync(context);

            if (!CompareValues(actualValue, expectedValue, Operator))
                return false;
        }

        return true;
    }
}

// 复合条件：逻辑组合
public class CompositeCondition : Condition
{
    public LogicOperator Operator { get; set; } = LogicOperator.And;
    public List<Condition> SubConditions { get; set; } = new();

    public override async Task<bool> EvaluateAsync(ConditionContext context)
    {
        if (!SubConditions.Any()) return true;

        return Operator switch
        {
            LogicOperator.And => await EvaluateAllAsync(context),
            LogicOperator.Or => await EvaluateAnyAsync(context),
            LogicOperator.Not => !await EvaluateAllAsync(context),
            LogicOperator.Xor => await EvaluateXorAsync(context),
            _ => false
        };
    }

    private async Task<bool> EvaluateAllAsync(ConditionContext context)
    {
        foreach (var condition in SubConditions)
        {
            if (!await condition.EvaluateAsync(context))
                return false;
        }
        return true;
    }

    private async Task<bool> EvaluateAnyAsync(ConditionContext context)
    {
        foreach (var condition in SubConditions)
        {
            if (await condition.EvaluateAsync(context))
                return true;
        }
        return false;
    }

    private async Task<bool> EvaluateXorAsync(ConditionContext context)
    {
        int trueCount = 0;
        foreach (var condition in SubConditions)
        {
            if (await condition.EvaluateAsync(context))
                trueCount++;
        }
        return trueCount == 1; // 只有一个为真
    }
}
```

```csharp
public class JsonConditionFactory
{
    public async Task<List<CardAbility>> LoadAbilitiesFromDatabaseAsync()
    {
        var abilities = new List<CardAbility>();
        var dbRecords = await _repository.GetAllAbilitiesAsync();

        foreach (var record in dbRecords)
        {
            var conditionConfig = JsonSerializer.Deserialize<ConditionConfig>(record.ConditionConfig);
            var condition = await BuildConditionFromConfigAsync(conditionConfig);

            var ability = new CardAbility
            {
                Id = record.Id,
                CardId = record.CardId,
                Name = record.AbilityName,
                Conditions = new List<Condition> { condition }
            };
            abilities.Add(ability);
        }

        return abilities;
    }

    private async Task<Condition> BuildConditionFromConfigAsync(ConditionConfig config)
    {
        return config.Type switch
        {
            "property" => new PropertyCondition
            {
                TargetExpression = config.Target,
                Operator = ParseOperator(config.Operator),
                ExpectedValue = ParseValue(config.Value)
            },
            "count" => new CountCondition
            {
                Target = await BuildTargetFromConfigAsync(config.Target, config.Filters),
                Operator = ParseOperator(config.Operator),
                ExpectedValue = ParseValue(config.Value)
            },
            "composite" => new CompositeCondition
            {
                Operator = ParseLogicOperator(config.Operator),
                SubConditions = await Task.WhenAll(
                    config.Conditions.Select(BuildConditionFromConfigAsync))
            },
            _ => throw new ArgumentException($"Unknown condition type: {config.Type}")
        };
    }
}
```
