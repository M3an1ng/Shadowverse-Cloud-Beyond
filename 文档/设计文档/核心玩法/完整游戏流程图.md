# 完整游戏对战流程图 (v1.1)

## 概述

本文档旨在通过流程图详细拆解类《影之诗》卡牌游戏的完整对战流程，包含从游戏开始到结束的各个阶段、玩家动作、系统判定及效果结算。此文档将作为后续功能开发的主要流程依据。(v1.1: 细化了使用卡牌流程，区分随从/护符入场节点和法术结算)

## 详细流程图

```mermaid
graph TD
    StartGame((游戏开始)) --> Init[初始化游戏状态\n(HP, 牌库, 初始PP=0, EP=0)];
    Init --> Mulligan[调度阶段\n(抽取初始手牌, 玩家选择替换)];
    Mulligan --> DetermineFirstPlayer[决定先手玩家];
    DetermineFirstPlayer --> TurnStart_T1[回合 1 开始 (先手玩家)];

    subgraph 完整回合周期 [玩家回合]
        direction TB
        TurnStart(回合开始) --> CheckDeckout{检查牌库是否为空?};
        CheckDeckout -- 是 --> GameOver_Deckout((游戏结束 - 牌库抽空));
        CheckDeckout -- 否 --> IncreaseMaxPP[增加最大PP上限\n(若<10, 触发事件)];
        IncreaseMaxPP --> RefillPP[回复当前PP至最大值];
        RefillPP --> DrawCard[抽取卡牌];
        DrawCard --> CheckHandSize{检查手牌是否超上限?};
        CheckHandSize -- 是 --> DiscardExcess[弃掉超上限卡牌];
        CheckHandSize -- 否 --> ResetStates[重置场上随从攻击状态\n(移除召唤失调等)];
        DiscardExcess --> ResetStates;
        ResetStates --> ProcessStartTurnEffects[处理“回合开始时”效果];
        ProcessStartTurnEffects --> CheckGameOver_Start{检查游戏结束条件?};
        CheckGameOver_Start -- 是 --> GameOver((游戏结束));
        CheckGameOver_Start -- 否 --> EnterMainPhase[进入主阶段];

        EnterMainPhase --> MainPhaseActions{主阶段: 玩家动作循环};

        %% --- 使用卡牌流程细化 ---
        MainPhaseActions -- 使用卡牌 --> PlayCardAction[选择手牌];
        PlayCardAction --> CheckPlayable{检查使用条件?\n(PP, 阶段, 目标等)};
        CheckPlayable -- 否 --> MainPhaseActions;
        CheckPlayable -- 是 --> SelectTarget_Play[选择目标 (若需要)];
        SelectTarget_Play --> ExecutePlayCard[验证, 支付费用\n卡牌移出 手牌->处理区];

        ExecutePlayCard -- 是随从/护符 --> EntityEntersField[**随从/护符 进入战场 (触发点)**];
        EntityEntersField --> ResolveFanfare[结算 入场曲 / 播放时效果];
        ResolveFanfare --> PlaceOnBoard_FA[随从/护符 放置到战场格];
        PlaceOnBoard_FA --> CheckGameOver_Play{检查游戏结束条件?};

        ExecutePlayCard -- 是法术 --> ResolveSpell[结算 法术效果];
        ResolveSpell --> MoveSpellToGrave[法术 移动到墓地];
        MoveSpellToGrave --> CheckGameOver_Play; % 也需要检查游戏是否结束

        CheckGameOver_Play -- 是 --> GameOver;
        CheckGameOver_Play -- 否 --> MainPhaseActions; % 返回主阶段动作循环
        %% --- 使用卡牌流程结束 ---

        MainPhaseActions -- 进化 --> EvolveAction[选择场上可进化随从];
        EvolveAction --> CheckEvolvable{检查进化条件?\n(EP, 回合数, 状态)};
        CheckEvolvable -- 否 --> MainPhaseActions;
        CheckEvolvable -- 是 --> ExecuteEvolve[执行进化\n(扣EP, 改变状态/属性)];
        ExecuteEvolve --> ResolveEffects_Evolve[结算进化效果/进化时效果];
         ResolveEffects_Evolve --> CheckGameOver_Evolve{检查游戏结束条件?};
         CheckGameOver_Evolve -- 是 --> GameOver;
         ResolveEffects_Evolve -- 否 --> MainPhaseActions;

        MainPhaseActions -- 攻击 --> AttackAction[选择场上可攻击随从];
        AttackAction --> CheckCanAttack{检查攻击条件?\n(攻击状态, 突进/疾驰)};
        CheckCanAttack -- 否 --> MainPhaseActions;
        CheckCanAttack -- 是 --> SelectTarget_Attack[选择攻击目标\n(随从/主战者)];
        SelectTarget_Attack --> CheckValidTarget{检查目标合法性?\n(处理守护 Ward 等)};
        CheckValidTarget -- 否 --> MainPhaseActions; % 可允许重新选择目标
        CheckValidTarget -- 是 --> ExecuteAttack[执行战斗结算];

        subgraph 战斗与破坏结算
            ExecuteAttack --> ApplyDamage[双方造成伤害];
            ApplyDamage --> CheckHealth_Attacker{攻击者生命 <= 0?};
            CheckHealth_Attacker -- 是 --> TriggerLastWords_Attacker(触发攻击者 亡语);
            TriggerLastWords_Attacker --> MoveToGrave_Attacker[移动攻击者到墓地];
             MoveToGrave_Attacker --> CheckHealth_Defender;
             CheckHealth_Attacker -- 否 --> CheckHealth_Defender;

             CheckHealth_Defender{防御者生命 <= 0?};
             CheckHealth_Defender -- 是 --> TriggerLastWords_Defender(触发防御者 亡语);
            TriggerLastWords_Defender --> MoveToGrave_Defender[移动防御者到墓地];
            MoveToGrave_Defender --> PostCombat;
            CheckHealth_Defender -- 否 --> PostCombat;
        end

        PostCombat --> MarkAttacked[标记攻击者本回合已攻击];
        MarkAttacked --> CheckGameOver_Attack{检查游戏结束条件?};
        CheckGameOver_Attack -- 是 --> GameOver;
        CheckGameOver_Attack -- 否 --> MainPhaseActions; % 攻击后返回主阶段

        MainPhaseActions -- 结束回合 --> TriggerEndTurn[玩家点击结束回合];
        TriggerEndTurn --> ProcessEndTurnEffects[处理“回合结束时”效果];
        ProcessEndTurnEffects --> CheckGameOver_End{检查游戏结束条件?};
        CheckGameOver_End -- 是 --> GameOver;
        CheckGameOver_End -- 否 --> SwitchPlayer[切换当前玩家];
    end

    TurnStart_T1 --> TurnStart; % 进入回合循环
    SwitchPlayer --> NextTurnStart(下一玩家回合开始);
    NextTurnStart --> TurnStart; % 循环回当前玩家的回合开始
```

## 流程说明

- **初始化:** 设置游戏基本状态，包括玩家 HP、牌库、初始 PP(0)、初始 EP(0)等。
- **调度(Mulligan):** 允许玩家更换初始手牌。
- **回合开始:** 检查牌库、增加/回复 PP、抽卡、处理手牌上限、重置随从状态、触发回合开始效果、检查胜负。
- **主阶段:** 玩家可以循环执行多种动作：
  - **使用卡牌:**
    - 检查费用和条件 -> 选择目标 -> 支付费用并将卡牌移出 手牌。
    - **(若是随从/护符):** **进入战场 (触发点)** -> 结算入场曲等效果 -> 放置到战场。
    - **(若是法术):** 结算效果 -> 移入墓地。
    - -> 检查胜负。
  - **进化:** 检查条件 -> 执行 -> 结算效果 -> 检查胜负。
  - **攻击:** 选择攻击者 -> 检查攻击条件 -> 选择目标 -> 检查目标合法性 (守护等) -> 执行战斗 -> 处理伤害 -> 检查破坏与结算亡语 -> 检查胜负。
- **回合结束:** 触发回合结束效果 -> 检查胜负 -> 切换玩家。
- **胜负判定:** 在流程中的多个关键节点（抽卡后、造成伤害后、效果结算后、回合结束时）都需要检查一方主战者生命值是否 <= 0 或其他特殊胜利/失败条件。

## 重要提示：事件触发机制 (Event Trigger Mechanism)

**请注意：** 上述流程图中的许多步骤（如回合开始 `TurnStart`、卡牌使用 `PlayCard`、**随从/护符进入战场 `EntityEntersField`**、随从攻击 `Attack`、受到伤害 `DamageTaken`、随从/护符破坏 `Destroyed`、回合结束 `TurnEnd` 等）都是潜在的游戏**事件触发点 (Triggers)**。

未来在设计和实现卡牌能力时，需要建立一个健壮的**事件系统 (Event System)** 来处理这些触发条件。当特定事件发生时（例如 `event:PlayCard`, `event:FollowerAttacks`, `event:CharacterTakesDamage`），系统需要能够：

1.  **广播 (Broadcast)** 该事件及其相关信息（如来源、目标、数值等）。
2.  **监听 (Listen)**：允许卡牌或游戏规则注册对特定事件的监听。
3.  **响应 (Respond)**：按照优先级和结算规则，执行监听该事件的效果。

此外，卡牌能力本身也可能引入新的、更复杂的触发条件和事件（例如“当己方场上有 X 个随从时...”）。这个流程图为识别游戏流程中**基础的、固有的**事件触发点提供了框架，是构建事件系统的起点。
