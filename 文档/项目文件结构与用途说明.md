# 项目文件结构与用途说明 V1.1

本说明旨在清晰地描述《影之诗》网页版 Demo 项目的当前文件和目录结构，以及各个组成部分的主要用途，便于项目维护和后续开发。

## 1. 总体结构概览

项目采用纯前端技术栈 (HTML, CSS, JavaScript)，利用 ES Modules 实现 JavaScript 代码的模块化管理。目前不使用 Node.js 包管理器 (`package.json` 不存在)。

## 2. 根目录文件

- **`index.html`**:
  - **用途:** 游戏的主 HTML 文件，定义网页骨架和游戏界面的基本布局（如玩家信息区、手牌区、战场区等）。
  - **关键:** 包含对 `style.css` 的链接和对 `src/main.js` 的脚本引用（`type="module"` 必须设置）。
- **`style.css`**:
  - **用途:** 包含所有的 CSS 规则，负责定义游戏界面的视觉样式、布局（如使用 Grid）、元素外观以及各种状态的视觉反馈（如卡牌可选中、可攻击的高亮）。
- **`script.js`**:
  - **用途:** **(已废弃)** 项目早期的单体 JavaScript 文件，包含了所有逻辑。其功能已被 `src/` 目录下的模块取代。**不应再被引用或修改。**

## 3. `/data` 目录

存放游戏的核心数据。

- **`card_data.json`**:
  - **用途:** **卡牌数据库**。以 JSON 数组格式存储所有卡牌的静态定义信息，包括 ID、名称、费用、类型、攻防、描述、关键字、效果、进化信息、目标需求等。这是 `cardManager.js` 加载和处理的基础。

## 4. `/src` 目录

存放模块化的 JavaScript 代码，遵循 ES Modules 标准。参考 [`文档/技术文档/代码结构初步设计.md`](文档/技术文档/代码结构初步设计.md:0)。

- **`main.js`**:
  - **用途:** **应用入口与初始化器**。负责导入其他核心模块，协调游戏的启动流程（加载数据 -> 初始化状态 -> 初始渲染），并设置少量顶层事件监听器（如结束回合按钮）。
- **`gameManager.js`**:
  - **用途:** **核心游戏逻辑管理器**。管理核心游戏状态 (`gameState`)，处理主要的游戏动作逻辑（如出牌 `playCard`、攻击 `initiateAttack`/`executeAttack`、效果结算等），管理游戏阶段，并协调与其他模块（Player, Card, Turn, AI）的交互。
- **`turnManager.js`**:
  - **用途:** **回合管理器**。负责处理回合的开始 (`startTurn`) 和结束 (`endTurn`) 逻辑，包括资源回复、抽卡、重置单位状态、触发回合效果（未来）等。
- **`cardManager.js`**:
  - **用途:** **卡牌管理器**。负责异步加载 `data/card_data.json`，提供卡牌定义查询，以及根据定义创建具有运行时状态（如 `uid`, `currentHealth`）的卡牌实例 (`createCardInstance`)。
- **`player.js`**:
  - **用途:** **玩家模块**。定义 `Player` 类或工厂函数，包含玩家的属性（HP, PP, EP, 手牌, 牌库, 战场, 墓地等）和相关操作（如抽卡 `drawCard`）。
- **`ui.js`**:
  - **用途:** **UI 管理器**。负责所有与 DOM 操作相关的代码，根据 `gameManager` 提供的状态渲染游戏界面 (`renderGame`)，处理用户交互事件（如卡牌点击、按钮点击），并将用户操作转化为对 `gameManager` 的调用。**不包含核心游戏逻辑**。
- **`ai.js`**:
  - **用途:** **AI 逻辑模块**。包含 AI 对手的决策逻辑 (`runAILogic`)，根据当前游戏状态决定出牌、攻击等行为。

## 5. `/info` 目录

存放信息性、参考性的数据。

- **`keyword.csv`**:
  - **用途:** **关键字参考数据库**。以 CSV 格式列出游戏中的关键字及其 ID、中英文名称和描述。目前主要供开发者参考，不直接被游戏运行时加载，但可能用于未来 UI 功能（如 Tooltips）。

## 6. `/文档` 目录 (重组后)

存放所有项目相关的设计、规划、记录文档。为了便于管理，已进行结构优化：

- **`/文档/技术文档/`**: 存放与技术实现、架构设计相关的文档。
  - `代码结构初步设计.md`: 描述了 V0.2 的模块化代码架构。
- **`/文档/设计文档/`**: 存放与游戏玩法、核心机制、AI 设计等相关的文档。
  - `AI设计文档_整体V1.0.md`: 合并后的 AI 逻辑设计 V1.0。
  - `核心玩法/`: 包含游戏核心流程、回合机制等详细设计。
- **`/文档/需求与分析/`**: 存放项目需求、背景分析、系统结构分析等文档。
  - `影之诗系统结构分析_V0.3.1.md`: 对标《影之诗》的系统结构研究。
- **`/文档/archive/`**: 存放不再活跃或已被取代的旧版本文档。
  - `AI设计文档_攻击逻辑V0.1.md`: 旧版 AI 攻击逻辑。
  - `AI设计文档_进化逻辑V0.1.md`: 旧版 AI 进化逻辑。
- **`/文档/已解决问题归档/`**: 存放已解决问题的相关记录或任务单。
  - `任务清单_script修复_已解决.md`: 示例。
- `工作备忘录.md`: 记录开发过程中的决策、任务、思考等（持续更新）。
- `项目初步构想与范围定义书.md`: 项目早期的目标和范围设定。
- `项目整体任务清单.md`: (如果存在) 跟踪项目的主要任务。
- `项目文件结构与用途说明.md`: (本文档) 提供文件结构和用途的快速参考。

## 7. 缺失的文件说明

- **`package.json` / `package-lock.json`**: 不存在。表明项目不使用 npm/yarn 进行依赖管理。
- **`node_modules/`**: 不存在。项目没有安装外部 Node.js 依赖。
