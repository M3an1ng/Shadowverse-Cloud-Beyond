# 开发者工具使用指南

## 🎯 概述

本项目提供了一套完整的开发者工具，帮助您快速测试和调试游戏功能，大幅简化开发和测试流程。

## 🛠️ 工具列表

### 1. 游戏内开发者控制台
- **位置**: 游戏界面右上角的 🛠️ 按钮
- **快捷键**: `Ctrl + `` (反引号)
- **功能**: 在游戏运行时直接执行命令

### 2. 独立开发者工具面板
- **文件**: `dev-tools.html`
- **功能**: 独立的调试界面，可与游戏并行使用

### 3. 自动化测试脚本
- **文件**: `test-automation.js`
- **功能**: 浏览器控制台中运行自动化测试

### 4. 一键启动脚本
- **文件**: `start-dev.ps1`
- **功能**: 自动启动开发环境

### 5. 测试运行器
- **文件**: `run-tests.ps1`
- **功能**: 简化单元测试执行

## 🚀 快速开始

### 方法1：一键启动（推荐）
```powershell
# 启动开发环境并打开所有工具
.\start-dev.ps1 -OpenBrowser -DevTools

# 等待服务器启动后，在游戏界面按 Ctrl + ` 打开控制台
```

### 方法2：手动启动
```powershell
# 1. 启动后端
cd Server
dotnet run

# 2. 启动前端（新终端）
cd ..
npx vite

# 3. 打开浏览器访问 http://localhost:5173
# 4. 按 Ctrl + ` 打开开发者控制台
```

## 🎮 游戏内控制台使用

### 基本操作
- **打开/关闭**: `Ctrl + `` 或点击右上角 🛠️ 按钮
- **命令历史**: 使用 ↑↓ 键浏览历史命令
- **清空**: 输入 `clear` 命令

### 常用命令

#### 游戏状态查看
```
help                    # 显示所有可用命令
gamestate              # 显示当前游戏状态
clear                  # 清空控制台
```

#### 游戏操作
```
play <cardId> [target]  # 出牌
attack <attacker> <target>  # 攻击
evolve <unitUid>       # 进化单位
endturn                # 结束回合
```

#### 调试功能
```
addcard <cardId>       # 添加卡牌到手牌（暂未实现）
setpp <amount>         # 设置PP（暂未实现）
setep <amount>         # 设置EP（暂未实现）
damage <target> <amount>  # 造成伤害（暂未实现）
heal <target> <amount>    # 治疗（暂未实现）
```

## 🔧 独立开发者工具面板

### 启动方式
1. 直接打开 `dev-tools.html` 文件
2. 或使用启动脚本：`.\start-dev.ps1 -DevTools`

### 主要功能
- **连接管理**: 连接/断开服务器
- **游戏管理**: 创建/加入/离开游戏
- **卡牌测试**: 快速出牌测试
- **战斗测试**: 攻击、进化等操作
- **快速操作**: 一键设置测试环境
- **实时日志**: 查看所有游戏事件

### 使用流程
1. 确保后端服务器运行在 `http://localhost:5000`
2. 点击"连接服务器"
3. 设置游戏ID和玩家ID
4. 点击"创建游戏"或"加入游戏"
5. 使用各种测试功能

## 🤖 自动化测试

### 在浏览器控制台中运行
```javascript
// 快速测试所有功能
quickTest()

// 自定义测试
const tester = new GameTestAutomation();
await tester.runFullTestSuite();

// 单项测试
const tester = new GameTestAutomation();
await tester.connectToServer();
await tester.createTestGame();
await tester.testPlayCard();
```

### 测试报告
测试完成后会自动生成报告，显示：
- 总测试数量
- 通过/失败数量
- 成功率
- 详细的测试结果

## 📊 单元测试

### 运行所有测试
```powershell
.\run-tests.ps1
```

### 监视模式（推荐开发时使用）
```powershell
.\run-tests.ps1 -Watch
```

### 代码覆盖率
```powershell
.\run-tests.ps1 -Coverage
```

### 过滤测试
```powershell
.\run-tests.ps1 -Filter "Quick"  # 只运行包含"Quick"的测试
```

## 🆘 故障排除

### 控制台无法打开
- 检查是否正确导入了 `devConsole.js`
- 确认 `initDevConsole()` 已被调用
- 查看浏览器控制台是否有错误信息

### 连接服务器失败
- 确认后端服务器正在运行
- 检查端口是否正确（默认5000）
- 查看防火墙设置

### 命令执行失败
- 检查 SignalR 连接状态
- 确认游戏状态是否正确
- 查看服务器端日志

### 测试失败
- 确认测试环境配置正确
- 检查依赖项是否安装
- 查看具体的错误信息
