# 03-开发环境设置 [COMPLETED]

## 目的与范围

本文档提供Shadowverse-beyond项目的完整开发环境设置指南，包括环境要求、安装步骤、配置说明和常见问题解决方案。确保新开发者能够快速搭建可用的开发环境。

## 核心概念

### 开发环境架构
- **前端开发**: Vite开发服务器 + 浏览器调试
- **后端开发**: .NET CLI + Visual Studio Code/Visual Studio
- **数据库**: SQLite本地文件数据库
- **通信**: 本地代理配置实现前后端联调

## 安装步骤

### 1. 克隆项目
```bash
git clone [项目仓库地址]
cd Shadowverse-beyond
```

### 2. 后端环境设置

#### 安装依赖包
```bash
cd Server
dotnet restore
```

#### 数据库初始化
```bash
# 创建数据库迁移 (如果需要)
dotnet ef migrations add InitialCreate

# 应用数据库迁移
dotnet ef database update

# 验证数据库文件创建
ls Data/shadowverse.db
```

#### 配置文件设置
<augment_code_snippet path="Server/appsettings.Development.json" mode="EXCERPT">
````json
{
  "ConnectionStrings": {
    "DefaultConnection": "Data Source=Data/shadowverse.db"
  },
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "Microsoft.AspNetCore.SignalR": "Debug",
      "ShadowverseBeyond": "Debug"
    }
  },
  "AllowedHosts": "*"
}
````
</augment_code_snippet>

#### 启动后端服务
```bash
# 开发模式启动
dotnet run

# 或使用监视模式 (自动重启)
dotnet watch run

# 验证服务运行
# 浏览器访问: http://localhost:5100
```

### 3. 前端环境设置

#### 安装依赖包
```bash
# 返回项目根目录
cd ..

# 安装前端依赖

```

## 集成点

### 前后端联调

#### 网络配置
```mermaid
graph LR
    Browser[浏览器<br/>localhost:5173] --> Vite[Vite开发服务器<br/>代理请求]
    Vite -->|/api/*| Backend[后端服务<br/>localhost:5100]
    Vite -->|/gamehub| Backend
    Backend --> SQLite[(SQLite数据库<br/>Data/shadowverse.db)]
```

#### 代理规则说明
- **API请求**: `/api/*` → `http://localhost:5100/api/*`
- **SignalR**: `/gamehub` → `http://localhost:5100/gamehub` (WebSocket)
- **静态文件**: 直接由Vite服务

### 日志配置

#### 后端日志

## 使用模式

### 日常开发流程
1. **启动后端**: `dotnet watch run`
2. **启动前端**: `npm run dev`
3. **代码修改**: 自动热重载
4. **测试功能**: 浏览器验证
5. **查看日志**: 控制台输出
6. **数据库检查**: SQLite工具

### 常见开发任务

#### 添加新功能
1. 后端: 创建DTO → 实现服务方法 → 添加Hub方法
2. 前端: 添加UI → 实现事件处理 → 测试交互

#### 数据库变更
1. 修改实体类
2. 添加迁移: `dotnet ef migrations add [Name]`
3. 更新数据库: `dotnet ef database update`
4. 验证数据结构
