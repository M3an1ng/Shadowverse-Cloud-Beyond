### 技术栈概览
- **后端**: ASP.NET Core 8, SignalR, Entity Framework Core, SQLite
- **前端**: 原生JavaScript ES6+, HTML5/CSS3, SignalR Client
- **开发工具**: Visual Studio Code, Vite, .NET CLI
- **数据库**: SQLite (开发), 支持迁移到PostgreSQL

## 🔧 核心架构

### 系统架构图
```mermaid
graph TB
    subgraph "前端层"
        UI[用户界面]
        GM[游戏管理器]
        CM[卡牌管理器]
    end

    subgraph "通信层"
        SignalR[SignalR Hub]
        API[REST API]
    end

    subgraph "后端层"
        GameService[游戏服务]
        AbilityManager[能力管理器]
        EconomyService[经济服务]
    end

    subgraph "数据层"
        EF[Entity Framework]
        DB[(SQLite数据库)]
    end

    UI --> GM
    GM --> SignalR
    GM --> API
    SignalR --> GameService
    API --> GameService
    GameService --> AbilityManager
    GameService --> EconomyService
    AbilityManager --> EF
    EconomyService --> EF
    EF --> DB
```

### 关键特性
- **🔄 实时同步**: SignalR确保游戏状态实时同步
- **⚡ 事件驱动**: 基于事件的游戏逻辑处理
- **🎯 能力系统**: 完整的卡牌能力管理和DSL解析
- **💎 进化机制**: 符合Shadowverse规则的进化系统
- **💰 经济生态**: 完整的金币、卡包和奖励系统
- **🏗️ Clean架构**: 分层设计，高内聚低耦合
