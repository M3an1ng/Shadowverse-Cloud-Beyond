## 🎮 项目简介

**Shadowverse Beyond** 是一个基于影之诗（Shadowverse）规则的网页版卡牌游戏 Demo，旨在实现完整的 1v1 对战体验，包含核心游戏机制如回合管理、卡牌出牌、战斗系统和进化机制。

### 🎯 项目目标

- **阶段一：** 网页版核心 Demo（当前阶段）
  - 实现基础的 1v1 玩家 vs AI 对战
  - 包含完整的游戏循环：抽卡、出牌、攻击、回合管理
  - 实现进化机制和基础 AI

- **阶段二：** 功能扩展
  - 增加更丰富的卡牌效果和机制
  - 改进 AI 智能度
  - 添加用户系统和卡组管理

- **阶段三：** Unity 迁移（规划中）
  - 调研 Unity 2D 开发方案
  - 规划代码迁移策略

## 🛠️ 技术栈

### 前端
- **HTML5/CSS3** - 基础页面结构和样式
- **JavaScript (ES6+)** - 游戏逻辑和用户交互
- **原生 DOM API** - 无框架依赖的轻量级实现

### 后端
- **C# .NET 8** - 服务器端游戏逻辑
- **SignalR** - 实时双向通信
- **Entity Framework Core** - 数据库 ORM
- **SQLite** - 轻量级数据库

### 架构特点
- **事件驱动架构** - 基于事件的游戏状态同步
- **前后端分离** - 清晰的职责划分
- **实时通信** - SignalR 确保游戏状态实时同步

## 🚀 快速开始

### 环境要求

- **.NET 8 SDK** - 后端开发和运行
- **现代浏览器** - 支持 ES6+ 的浏览器
- **Visual Studio Code** 或 **Visual Studio** - 推荐开发环境

### 安装步骤

1. **克隆项目**
   ```bash
   git clone [项目地址]
   cd Shadowverse-beyond
   ```

2. **启动后端服务**
   ```bash
   cd Server
   dotnet restore
   dotnet run
   ```

3. **访问游戏**
   - 打开浏览器访问 `http://localhost:5000`
   - 或直接打开 `index.html` 文件

### 开发环境配置

1. **后端开发**
   - 安装 .NET 8 SDK
   - 配置数据库连接（默认使用 SQLite）
   - 运行数据库迁移：`dotnet ef database update`

2. **前端开发**
   - 无需额外配置，直接编辑 JavaScript/CSS 文件
   - 推荐使用 Live Server 扩展进行实时预览

## 🎯 游戏规则

### 基础规则
- **生命值：** 每位玩家 20 点生命值
- **手牌上限：** 9 张卡牌
- **战场上限：** 7 个随从
- **PP 系统：** 每回合增加 1 点 PP（最大 10 点）

### 进化规则
- **先手玩家：** 第 5 回合开始可进化，最多 2 次
- **后手玩家：** 第 4 回合开始可进化，最多 3 次
- **进化效果：** +2/+2 属性提升，获得立即攻击能力

### 胜利条件
- 将对手生命值降至 0 或以下
- 对手无法抽卡（牌库耗尽）
