# 项目初步构想与范围定义书 (V0.2)

**版本:** 0.2
**日期:** 2025-05-22

## 1. 项目名称

Shadowverse-Beyond (暂定)

## 2. 项目愿景

开发一款受《影之诗》启发的集换式卡牌游戏。起点是一个功能虽简化但包含核心乐趣（特别是进化机制和基础法术）的网页版 Demo，逐步扩展功能，并探索未来迁移到 Unity 引擎的可能性。项目过程重视文档建设和知识传递，目标是让用户在实践中学习卡牌游戏开发。

## 3. 阶段一：概念验证与网页版核心 Demo (含简化进化与法术)

### 3.1 核心目标

实现一个可玩的 1v1 AI 对战网页 Demo，验证核心战斗流程、简化版进化机制以及基础法术效果的可行性。

### 3.2 主要功能

- **玩家 vs 简单 AI 对战:** 实现基础的对战框架。
- **核心战斗流程:**
  - **回合制管理 (Turn Management):** 回合开始/结束，资源结算，抽卡。
  - **资源系统 (PP):** 每回合最大值+1，回合开始时补满，上限通常为 10。
  - **出牌 (Play Card):** 从手牌将随从牌打出到战场，或使用法术牌，消耗对应 PP。
  - **进化 (Evolve - Simplified):**
    - 在特定回合后（例如，先手第 5 回合，后手第 4 回合）获得固定数量的进化点 (EP)，例如 2-3 个。
    - 每回合允许消耗 1 EP 主动进化一个场上符合条件的随从。
    - 进化效果：主要为属性提升 (如 ATK/HP +2/+2)，可附加简单异能（如 **突进 (Rush):** 进化回合即可攻击敌方随从）。
  - **攻击 (Attack):** 随从可以攻击敌方随从或敌方英雄。遵循基础攻击规则（如非突进随从需下一回合才能攻击，随从默认只能攻击一次等）。
  - **法术效果处理 (Spell Effect):** 实现基础法术效果的结算，例如直接伤害。需要考虑目标选择机制。
  - **胜利/失败条件:** 一方英雄生命值降至 0 或以下。
- **卡牌类型 (简化):**
  - **随从 (Follower):** 包含卡牌 ID, 名称, 类型("Follower"), 费用 (Cost), 攻击力 (Attack), 生命值 (Health), 卡面描述 (可选), 是否可进化(boolean), 进化后攻击力增量, 进化后生命值增量, 进化效果描述(例如附加 Rush)。
  - **法术 (Spell):** 包含卡牌 ID, 名称, 类型("Spell"), 费用 (Cost), 卡面描述, 效果列表 (例如: [{type: "Damage", target: "AnyEnemy", value: 2}] )。
- **基础 AI (Simple AI):**
  - 能够按规则出随从牌和使用法术牌（例如，在有目标且 PP 足够时使用伤害法术，优先解场）。
  - 会使用进化点（例如，优先进化能进行有利交换或攻击英雄的随从）。
  - 会进行攻击（例如，优先攻击能解掉的对方随从，其次攻击英雄）。
  - **目标:** 提供一个基础的、可交互的对手，而非高强度挑战。
- **基础用户界面 (Basic UI):**
  - 显示双方英雄生命值、当前/最大 PP、剩余 EP。
  - 显示手牌区域、战场区域（双方）。
  - 显示卡牌基本信息（鼠标悬停或点击时）。
  - 实现简单的卡牌拖拽出牌或点击出牌交互。
  - 实现法术/攻击的目标选择高亮提示。
  - 包含“回合结束”按钮。
- **卡牌数据管理:**
  - 使用 **JSON 文件** (`[`card_data.json`](card_data.json)`) 存储卡牌数据。
  - 设计易于理解和扩展的 JSON 结构，包含上述卡牌类型的必要字段，并为将来实现网页录入功能打好基础。

### 3.3 技术选型 (初步建议)

- **前端:** HTML5, CSS3, JavaScript (ES6+) - 核心逻辑将在 JS 中实现。
- **后端:** 暂定**纯前端**实现。
- **数据存储:** JSON 文件。
- **版本控制:** 强烈建议使用 Git 进行代码和文档管理。

## 4. 后续阶段展望

- **阶段二：网页版功能扩展与卡牌录入系统:** 加入更多卡牌异能（守护、必杀等）、护符卡，**开发网页端卡牌录入/编辑工具**，可能引入数据库，提升 AI 智能，增加卡组编辑功能。
- **阶段三：技术选型与 Unity 迁移准备:** 评估 Unity 方案，设计迁移策略。
- **阶段四：Unity 版本深化与网站功能转型:** 实现 Unity 版本，并将网站转为官网、卡牌数据库等。
