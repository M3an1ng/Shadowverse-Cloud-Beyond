# M7.2: HandleAttackAsync 实现计划 (Rev2)

**版本:** Rev3 (使用通用 HealthChangedEventDto)

**关联任务:** [M7.2: 实现 HandleAttackAsync](文档/项目整体任务清单.md)

**目标:** 在 `GameService` 中实现**分阶段**的单位攻击逻辑，统一处理对随从和玩家的伤害，并按正确顺序生成和广播事件。

## 1. DTO 定义

- 检查并确保以下 DTO 存在于 `Server/Dtos/SignalR/Events/`，如果不存在则创建：
  - `UnitAttackedEventDto.cs`: 包含攻击方和目标方单位的 `Uid`，用于“攻击时点”。
  - `PlayerAttackedEventDto.cs`: 包含攻击方单位的 `Uid` 和目标玩家 `PlayerId`，用于“攻击时点”。
  - `HealthChangedEventDto.cs`: (新增) 包含 `TargetUid` (受影响实体)、`NewHealth`、`ChangeAmount`，用于通用生命值变动报告。
- 依赖已存在的 DTO:
  - `DamageDealtEventDto.cs`
  - `UnitDestroyedEventDto.cs`
  - `GameOverEventDto.cs`
- 输入 DTO:
  - `AttackActionDto.cs`

## 2. 接口定义 (`IGameService.cs`)

- 在 [`Server/Application/Services/IGameService.cs`](Server/Application/Services/IGameService.cs) 中添加方法签名：
  ```csharp
  Task<List<GameEventDto>> HandleAttackAsync(string gameId, string playerId, AttackActionDto dto);
  ```

## 3. 服务实现 (`GameService.cs`)

- 在 [`Server/Application/Services/GameService.cs`](Server/Application/Services/GameService.cs) 中实现 `HandleAttackAsync` 方法。
- **核心逻辑流程:**

  ```mermaid
  graph TD
      A[Start HandleAttackAsync] --> B{Get GameState, Players};
      B --> C{Validation (Turn, Attacker, Target, Ward)};
      C -- Valid --> D[Mark Attacker Attacked];
      C -- Invalid --> Z[Return Empty/Error];

      D --> E{Target is Unit?};

      %% Phase 1: Attack Timing
      E -- Yes --> F_Unit[Phase 1: Gen UnitAttackedEvent];
      E -- No --> F_Player[Phase 1: Gen PlayerAttackedEvent];

      %% Phase 2: Clash Timing (Only if Target is Unit)
      F_Unit --> G[Phase 2: Clash Point (Future Effects)];
      F_Player --> H_Unified; %% Skip Phase 2 if target is Player

      %% Phase 3: Damage Timing (Unified Logic Start)
      G --> H_Unified[Phase 3: Damage Timing Start];

      H_Unified --> I[Apply Dmg: Attacker -> TargetEntity];
      I --> J[Gen DamageDealt (Target)];
      J --> K{Target is Player?};
      K -- Yes --> L[Gen PlayerHealthChanged];
      L --> M{Target is Unit?};  %% Check if Target is Unit for Counter-Attack
      K -- No --> M;

      M -- Yes --> N[Apply Dmg: Target -> Attacker];
      N --> O[Gen DamageDealt (Attacker)];
      O --> P_Unified; %% Go to Phase 4 Check
      M -- No --> P_Unified; %% Skip Counter-Attack if Target is Player

      %% Phase 4: Death Timing (Unified Checks)
      P_Unified --> Q[Check Attacker Death];
      Q -- Died --> R[Remove Attacker, Gen UnitDestroyed];
      R --> S[Check Target Death];
      Q -- Alive --> S;

      S --> T{Target is Unit?};
      T -- Yes --> U{Target Died?};
      U -- Yes --> V[Remove Target, Gen UnitDestroyed];
      V --> X[Return Events];
      U -- No --> X;

      T -- No --> W{Target Player Died?};
      W -- Yes --> Y[Set GameOver, Gen GameOver];
      Y --> X;
      W -- No --> X;

      X --> Z_End[End];
      Z --> Z_End;
  ```

- **实现细节:**
  - 获取 `GameStateDto`。
  - 验证：
    - 当前玩家是否是 `playerId`。
    - 游戏状态是否允许攻击。
    - 攻击者 (`attackerUid`) 是否存在于当前玩家场上，且 `CanAttack == true`。
    - 目标 (`targetUid`) 是否存在 (对方场上单位或 `"OpponentLeader"`)。
    - 守护 (Ward) 规则：如果对方场上有 `HasWard == true` 的单位，目标必须是这些单位之一（除非攻击者有特殊能力，暂不考虑）。
  - 如果验证成功：
    - 初始化 `List<GameEventDto> eventList`。
    - 找到攻击者 `attacker`，设置 `attacker.CanAttack = false`。
    - **Phase 1 (Attack Timing):**
      - 查找目标 `targetEntity` (可能是 `UnitStateDto` 或 `PlayerStateDto`)。
      - If `targetEntity` is Unit (`targetUnit`): 生成 `UnitAttackedEventDto`。
      - Else (`targetEntity` is Player `targetPlayer`): 生成 `PlayerAttackedEventDto`。
      - Add event to `eventList`.
      - _(TODO: 未来处理 "攻击时" 效果)_
    - **Phase 2 (Clash Timing - Unit Only):**
      - If `targetEntity` is Unit: _(TODO: 未来处理 "交战时" 效果)_
    - **Phase 3 (Damage Timing - Unified):**
      - 定义内部辅助方法 `ApplyDamage(IBoardEntityState entity, int damage, List<GameEventDto> events)` (假设 PlayerStateDto 和 UnitStateDto 实现共同接口 `IBoardEntityState` 含 `Uid`, `Health`):
        - `entity.Health -= damage;`
        - 生成 `DamageDealtEventDto { TargetUid = entity.Uid, Amount = damage }`。Add to `events`.
        - 生成 `HealthChangedEventDto { TargetUid = entity.Uid, NewHealth = entity.Health, ChangeAmount = -damage }`。Add to `events`. // 通用生命值变更事件
      - 调用 `ApplyDamage(targetEntity, attacker.Attack, eventList);`
      - If `targetEntity` is Unit (`targetUnit`): 调用 `ApplyDamage(attacker, targetUnit.Attack, eventList);`
      - _(TODO: 未来处理 "受到伤害时" 效果)_
    - **Phase 4 (Death Timing - Unified):**
      - 定义内部辅助方法 `CheckAndHandleDeath(IBoardEntityState entity, PlayerStateDto owner, PlayerStateDto opponent, List<GameEventDto> events)`:
        - If `entity.Health <= 0`:
          - If `entity` is `UnitStateDto unit`:
            - `owner.Board.Remove(unit);` (或标记为死亡)
            - 生成 `UnitDestroyedEventDto { UnitUid = unit.Uid }`。Add to `events`.
            - _(TODO: 处理 "离场/被破坏时" 效果)_
          - If `entity` is `PlayerStateDto player`:
            - 设置 `GameState.Status = GameStatus.GameOver;`
            - 设置 `GameState.WinnerPlayerId = opponent.PlayerId;`
            - 生成 `GameOverEventDto { WinnerPlayerId = opponent.PlayerId }`。Add to `events`.
      - 调用 `CheckAndHandleDeath(attacker, currentPlayer, opponentPlayer, eventList);`
      - 调用 `CheckAndHandleDeath(targetEntity, opponentPlayer, currentPlayer, eventList);` (注意 owner/opponent 关系)
    - 返回 `eventList`。

## 4. Hub 实现 (`GameHub.cs`)

- 在 [`Server/Presentation/Hubs/GameHub.cs`](Server/Presentation/Hubs/GameHub.cs) 中添加 `Attack` 方法:

  ```csharp
  public async Task Attack(AttackActionDto dto)
  {
      var gameId = _gameStateManager.GetGameIdForConnection(Context.ConnectionId);
      var playerId = _gameStateManager.GetPlayerIdForConnection(Context.ConnectionId);
      if (gameId == null || playerId == null) return; // Or throw

      var events = await _gameService.HandleAttackAsync(gameId, playerId, dto);

      // 广播事件 (可能需要优化广播目标)
      foreach (var gameEvent in events)
      {
          await Clients.Group(gameId).SendAsync(gameEvent.EventType, gameEvent);
      }
  }
  ```
