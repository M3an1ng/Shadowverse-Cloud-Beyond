# Bug 修复记录

本目录记录项目开发过程中遇到的重要 Bug 及其修复过程，为后续开发和维护提供参考。

## 文档结构

### 命名规范
- 使用数字前缀表示修复优先级和时间顺序
- 格式：`XX-Bug类型-简要描述.md`
- 例如：`01-换牌系统-回合验证错误.md`

### 文档模板
每个 Bug 修复文档应包含以下部分：

1. **问题描述**
   - Bug 现象
   - 复现步骤
   - 影响范围

2. **根因分析**
   - 技术层面的根本原因
   - 相关代码位置
   - 架构设计问题（如有）

3. **解决方案**
   - 修复策略
   - 具体代码更改
   - 测试验证

4. **架构影响**
   - 对系统架构的影响
   - 长期设计考虑
   - 后续改进建议

5. **验证结果**
   - 测试方法
   - 验证结果
   - 回归测试
