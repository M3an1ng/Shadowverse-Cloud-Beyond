# BUG-022: 进化点（EP）未按规则解锁及显示错误

**报告日期:** 2025-07-17

**报告人:** User

**优先级:** 高

---

## 1. 问题描述

游戏核心机制“进化”无法正常使用。进化点（Evolve Points, EP）没有在规定的回合解锁，并且其初始值和上限值在整个游戏过程中都未发生变化，导致玩家无法进化随从。

## 2. 复现步骤

1.  启动一局新的游戏。
2.  观察双方玩家的进化点（EP）显示。
3.  持续进行游戏，直到先手玩家进入第5回合。
4.  观察先手玩家的EP状态。
5.  继续进行游戏，直到后手玩家进入第4回合。
6.  观察后手玩家的EP状态。

## 3. 期望结果

-   **游戏开始时:** 双方玩家的EP都应为 `0/0` (当前可用/上限)。
-   **先手玩家第5回合开始时:** 先手玩家的EP应解锁，状态变为 `2/2`。
-   **后手玩家第4回合开始时:** 后手玩家的EP应解锁，状态变为 `3/3`。

## 4. 实际结果

-   从游戏开始到结束，双方玩家的EP始终为 `0/0` 或其他不正确/未初始化的值。
-   在规定的回合，EP没有解锁，数量和上限都没有发生变化。

## 5. 初步分析（待补充）

问题可能存在于以下一个或多个环节：
-   **回合管理逻辑:** 在回合开始的事件处理中，缺少检查当前回合数并根据规则解锁EP的逻辑。
-   **玩家状态实体 (`PlayerState.cs`):** `PlayerState` 中可能缺少EP相关的字段（如 `EvolvePoints`, `MaxEvolvePoints`），或者这些字段没有被正确地初始化和更新。
-   **状态同步:** EP状态更新后，可能没有通过相应的网络事件（如 `EvolvePointsUpdatedEvent`）通知客户端，导致UI不刷新。

## 6. 修复计划（待补充）

1.  **代码定位:** 检查与回合开始、玩家状态相关的服务和实体类。
2.  **逻辑实现:** 在回合开始的逻辑流中，加入EP解锁规则的判断和执行代码。
3.  **状态更新:** 确保 `PlayerState` 被正确更新。
4.  **客户端同步:** 实现或确保 `EvolvePointsUpdatedEvent` 被正确发送和处理。
5.  **测试验证:** 完整测试上述所有期望结果。
