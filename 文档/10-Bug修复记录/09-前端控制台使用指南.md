# 前端开发者控制台使用指南

## 🎯 快速开始

### 打开控制台
- **快捷键**: `Ctrl + `` (反引号键)
- **UI按钮**: 点击游戏界面右上角的🛠️按钮
- **浏览器控制台**: 输入 `window.devConsole.toggle()`

### 基本使用流程
1. **检查连接**: `connection` - 确认SignalR连接状态
2. **查看游戏状态**: `gamestate` - 显示当前游戏信息
3. **开启事件监听**: `monitor on` - 监听游戏事件流
4. **执行游戏操作**: 使用各种游戏命令
5. **获取帮助**: `help` - 查看完整命令列表

## 📋 命令参考

### 基础命令
| 命令 | 用法 | 说明 |
|------|------|------|
| `help` | `help` | 显示完整帮助信息 |
| `clear` | `clear` | 清空控制台输出 |
| `connection` | `connection` | 检查SignalR连接状态 |
| `gamestate` | `gamestate` | 显示当前游戏状态 |

### 游戏操作命令
| 命令 | 用法 | 说明 |
|------|------|------|
| `play` | `play <cardUid> [targetUid]` | 出牌，需要卡牌GUID |
| `attack` | `attack <attackerUid> <targetUid>` | 攻击，需要攻击者和目标GUID |
| `evolve` | `evolve <unitUid>` | 进化单位，需要单位GUID |
| `endturn` | `endturn` | 结束当前回合 |

### 调试工具命令
| 命令 | 用法 | 说明 |
|------|------|------|
| `events` | `events` | 显示事件监听状态 |
| `monitor` | `monitor <on\|off>` | 开启/关闭事件监听 |

## 🔧 高级使用技巧

### 1. GUID获取方法
```javascript
// 在浏览器控制台中获取手牌GUID
gameState.localPlayer.hand.forEach((card, index) => {
    console.log(`手牌${index}: ${card.uid} - ${card.name}`);
});

// 获取场上单位GUID
gameState.localPlayer.board.forEach((unit, index) => {
    console.log(`场上${index}: ${unit.uid} - ${unit.name}`);
});
```

### 2. 事件监听调试
```
> monitor on          # 开启事件监听
> play <cardUid>      # 执行操作
> monitor off         # 关闭事件监听
```

### 3. 连接问题排查
```
> connection          # 检查连接状态
# 如果显示未连接，等待游戏完全加载后重试
# 如果持续问题，刷新页面重新连接
```

## ⚠️ 注意事项

### GUID格式要求
- **正确格式**: `12345678-1234-1234-1234-123456789abc`
- **错误格式**: `123`, `invalid-guid`, `12345678123412341234123456789abc`
- 所有游戏实体都使用标准GUID格式

### 命令执行限制
- 只能在自己的回合执行操作命令
- 卡牌必须在手牌中才能出牌
- 单位必须能够攻击才能执行攻击命令
- 进化需要消耗EP且满足进化条件

### 错误处理
- 无效GUID会显示格式错误提示
- 游戏规则违反会收到服务器错误消息
- 连接问题会显示连接状态错误

## 🔍 故障排除

### 常见问题

#### 1. 控制台无法打开
- **解决**: 确保游戏完全加载后再尝试
- **检查**: 浏览器控制台是否有JavaScript错误

#### 2. 命令无响应
- **解决**: 运行 `connection` 检查连接状态
- **检查**: SignalR连接是否为Connected状态

#### 3. GUID格式错误
- **解决**: 使用浏览器控制台获取正确的GUID
- **检查**: 确保GUID格式为 `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`

#### 4. 游戏操作失败
- **解决**: 检查游戏规则是否允许该操作
- **检查**: 确认是否在正确的游戏阶段和回合

### 调试步骤
1. 运行 `connection` 检查连接
2. 运行 `gamestate` 查看游戏状态
3. 运行 `monitor on` 开启事件监听
4. 执行问题操作并观察事件流
5. 检查浏览器控制台的错误信息
