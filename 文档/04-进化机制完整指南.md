## 🎯 概述

## 📋 进化规则

### 基础规则
- **进化点 (EP) 系统**：
  - 先手玩家：第5回合解锁，最多2点EP
  - 后手玩家：第4回合解锁，最多3点EP
  - EP不会自动回复，只在解锁时获得

- **进化限制**：
  - 每回合最多进化1次
  - 只有随从卡可以进化
  - 已进化的随从不能再次进化

- **进化效果**：
  - 属性提升：+2/+2
  - 获得立即攻击能力（无视召唤疲劳）
  - 触发进化时效果（如果有）

### 进化时机
- 只能在自己的主要阶段进行
- 必须有可用的EP
- 必须有符合条件的随从在场

```csharp
private void UnlockEvolutionIfNeeded(PlayerStateDto playerState, int turnNumber)
{
    bool isFirstPlayer = playerState.PlayerId == "player1";
    
    if (isFirstPlayer && turnNumber == 5 && playerState.MaxEP == 0)
    {
        playerState.MaxEP = 2;
        playerState.CurrentEP = 2;
        playerState.CanEvolve = true;
    }
    else if (!isFirstPlayer && turnNumber == 4 && playerState.MaxEP == 0)
    {
        playerState.MaxEP = 3;
        playerState.CurrentEP = 3;
        playerState.CanEvolve = true;
    }
}
```

#### 进化处理逻辑
```csharp
// 进化验证和执行 (GameService.cs)
public async Task<List<GameEventDto>> EvolveAsync(string gameId, string playerId, string unitUid)
{
    // 1. 基础验证
    ValidateEvolveConditions(gameState, playerState, unitToEvolve);
    
    // 2. 消耗EP
    playerState.CurrentEP--;
    playerState.CanEvolve = false; // 每回合只能进化一次
    
    // 3. 应用进化效果
    unitToEvolve.CurrentAttack += 2;
    unitToEvolve.CurrentHealth += 2;
    unitToEvolve.MaxHealth += 2;
    unitToEvolve.IsEvolved = true;
    unitToEvolve.CanAttack = true; // 获得立即攻击能力
    
    // 4. 生成事件
    var events = new List<GameEventDto>
    {
        new UnitEvolvedEventDto(unitToEvolve, playerId),
        new EpUpdateEventDto(playerId, playerState.CurrentEP, playerState.MaxEP)
    };
    
    return events;
}
```

```javascript
// 游戏管理 (gameManager.js)
function evolveCard(unitUid) {
    const playerState = getPlayerState('player1');
    
    // 客户端验证
    if (!playerState.canEvolve) {
        console.warn("GM: EvolveCard rejected - Local state indicates evolution already used or unavailable.");
        alert("本回合已使用过进化点或无法进化。");
        return;
    }
    
    // 发送进化请求
    if (connection && connection.state === signalR.HubConnectionState.Connected) {
        connection.invoke("PerformEvolve", unitUid)
            .catch(err => console.error("GM Error: Failed to send evolve action:", err));
    }
}
```

```javascript
function handleEpUpdate(eventData) {
    const playerToUpdate = getPlayerState(eventData.SourcePlayerId);
    if (playerToUpdate) {
        playerToUpdate.ep = eventData.CurrentEp;
        playerToUpdate.maxEP = eventData.MaxEp;
        playerToUpdate.canEvolve = playerToUpdate.maxEP > 0 && playerToUpdate.ep > 0;
        
        updateEpDisplay(playerToUpdate.id, playerToUpdate.ep, playerToUpdate.maxEP);
        renderGame(gameState);
    }
}
```

## 🎮 用户体验流程

### 进化操作流程
1. **条件检查**：玩家在主要阶段，有EP，有可进化随从
2. **按钮显示**：符合条件的随从显示"进化"按钮
3. **点击进化**：玩家点击进化按钮
4. **客户端验证**：前端进行基础验证
5. **发送请求**：通过SignalR发送进化请求
6. **服务器处理**：后端验证并执行进化逻辑
7. **事件广播**：广播进化事件和EP更新事件
8. **界面更新**：前端接收事件并更新界面

### 视觉反馈
- **EP显示**：实时显示当前EP/最大EP
- **进化按钮**：只在可进化时显示
- **属性变化**：进化后立即显示新的攻击力/生命值
- **视觉标识**：进化后的随从有特殊标识

## 🐛 已修复问题

### 问题1：进化按钮点击错误
- **现象**：点击进化按钮显示"本回合已使用过进化点或无法进化"
- **原因**：前端属性名不一致（canEvolveThisTurn vs canEvolve）
- **解决**：统一使用canEvolve属性名

### 问题2：状态同步延迟
- **现象**：进化后按钮不立即消失
- **原因**：后端设置CanEvolve=false后没有立即通知前端
- **解决**：进化后发送额外的EpUpdateEvent同步状态

### 问题3：调试日志过多
- **现象**：控制台充满调试信息
- **原因**：开发过程中添加了大量调试日志
- **解决**：清理调试日志，只保留必要的错误和状态日志
