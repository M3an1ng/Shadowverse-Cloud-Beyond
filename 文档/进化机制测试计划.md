# 进化机制测试计划

## 测试目标

验证完善后的进化机制在各种场景下都能正常工作，包括前后端数据同步、UI交互、AI行为等。

## 测试环境准备

### 启动游戏
1. 启动后端服务器：`cd Server && dotnet run`
2. 启动前端服务器：`cd .. && npx vite`
3. 在浏览器中打开游戏：`http://localhost:5173`

### 游戏设置
- 玩家1：人类玩家
- 玩家2：AI玩家
- 确保有可进化的随从卡牌在手牌中

## 测试用例

### TC001: 基础进化功能测试

**目标：** 验证基本进化功能正常工作

**前置条件：**
- 游戏进行到第5回合（先手）或第4回合（后手）
- 玩家有EP可用
- 场上有未进化的随从

**测试步骤：**
1. 确认进化按钮在符合条件的随从上显示
2. 点击进化按钮
3. 观察进化动画和状态变化

**预期结果：**
- 随从属性提升（+2/+2）
- EP消耗1点
- 随从获得立即攻击能力
- UI正确更新显示

### TC002: 进化条件限制测试

**目标：** 验证各种进化限制条件

**子测试：**

#### TC002-1: 回合限制测试
**步骤：**
1. 在第1-3回合尝试进化
2. 确认无进化按钮显示

**预期：** 进化按钮不显示，无法进化

#### TC002-2: EP不足测试
**步骤：**
1. 消耗所有EP
2. 尝试进化随从

**预期：** 进化按钮不显示或点击无效

#### TC002-3: 已进化单位测试
**步骤：**
1. 进化一个随从
2. 尝试再次进化同一随从

**预期：** 进化按钮不再显示

#### TC002-4: 非主阶段测试
**步骤：**
1. 在对手回合尝试进化

**预期：** 无法进行任何进化操作

### TC003: 前后端数据同步测试

**目标：** 验证进化事件的正确广播和处理

**测试步骤：**
1. 打开浏览器开发者工具，监控网络请求
2. 执行进化操作
3. 检查SignalR事件传输

**预期结果：**
- 发送正确的 `EvolveActionDto`
- 接收到 `UnitEvolvedEventDto`
- 接收到 `EpUpdateEventDto`
- 接收到 `StatChangeEventDto`
- 所有事件数据格式正确

### TC004: AI进化行为测试

**目标：** 验证AI能正确使用进化机制

**测试步骤：**
1. 让AI获得进化权限（第4回合）
2. 确保AI场上有可进化随从
3. 观察AI的进化决策

**预期结果：**
- AI在合适时机进化随从
- AI进化后的随从能正确攻击
- AI进化决策符合基本策略

### TC005: UI交互测试

**目标：** 验证用户界面的正确性

**测试步骤：**
1. 检查进化按钮的显示条件
2. 测试按钮点击响应
3. 验证进化后的视觉反馈

**预期结果：**
- 进化按钮在正确条件下显示
- 点击响应及时
- 进化后随从外观有明显变化
- EP显示正确更新

### TC006: 边界情况测试

**目标：** 测试各种边界和异常情况

#### TC006-1: 网络中断测试
**步骤：**
1. 进化过程中断开网络
2. 重新连接后检查状态

**预期：** 状态能正确恢复或给出错误提示

#### TC006-2: 快速连续操作测试
**步骤：**
1. 快速连续点击进化按钮
2. 同时进行其他操作

**预期：** 不会出现重复进化或状态错误

#### TC006-3: 游戏结束时进化测试
**步骤：**
1. 在游戏即将结束时尝试进化

**预期：** 正确处理游戏结束状态

## 性能测试

### PT001: 进化响应时间测试

**目标：** 确保进化操作响应及时

**测试方法：**
1. 记录从点击进化按钮到UI更新完成的时间
2. 测试10次取平均值

**预期：** 响应时间 < 500ms

### PT002: 内存使用测试

**目标：** 确保进化操作不会造成内存泄漏

**测试方法：**
1. 连续进行50次进化操作
2. 监控浏览器内存使用

**预期：** 内存使用稳定，无明显泄漏

### 测试脚本

可以考虑编写简单的测试脚本来自动化部分测试：

```javascript
// 示例：自动进化测试脚本
function autoEvolveTest() {
    // 查找可进化的随从
    const evolveButtons = document.querySelectorAll('.evolve-button');
    if (evolveButtons.length > 0) {
        console.log(`Found ${evolveButtons.length} evolvable units`);
        evolveButtons[0].click();
        return true;
    }
    return false;
}
```

4. **错误记录：** 详细记录所有发现的问题
5. **性能监控：** 关注测试过程中的性能表现
